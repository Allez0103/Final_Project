## 포함·제외

전체 애플리케이션 Python 소스 107개 모듈, 테스트, 빌드·DB 스키마 설정,
구현 문서, 아이콘·로고·영상 템플릿·Noto Sans KR 글꼴과 라이선스를 포함합니다.
CAD/STEP/BREP·프로젝트 DB·실행 로그·영상·학습 데이터·실행 파일·빌드 결과·가상환경은 제외합니다.
데이터가 함께 묶인 `assets/pilot` 전체를 제외하므로 GitHub 소스에는 초기 학습 모델도 없습니다.
학습·추천·모델 관리 코드는 유지하며 별도 모델 번들이 없는 빌드는 기존 규칙으로 시작합니다.
기존 사용자 데이터의 모델을 삭제하거나 바꾸지 않습니다.

사내 실행 배포본에는 기존 승인 모델·고정 참조 번들이 포함되어 있으며,
이 데이터 제외 GitHub 소스 사본과 초기 모델 상태가 다릅니다.

## 이번 변경

ver1_06 이후 기준 부품 시점·카메라 캡처·그룹 보호·선택 동기화, 콤보박스 휠 동작,
카드↔재생바 연동·별도 화면 박스·생성 기록 팝업, 메모리/표시 메시 최적화를 반영했습니다.
영상은 Noto Sans KR과 단색 상·하단 템플릿을 사용하며 제목의 완제품 확장자를 제거합니다.
MP4 저장·내보내기는 프로젝트명을 기본으로 사용하고 중복 시 번호를 붙입니다.
새 이름에서도 재열기·이전 영상 정리를 지원합니다.
자세한 변경과 기존 제한은 ZIP의 `docs/RELEASE_VER1_07.md`, V33~V41 문서에 있습니다.
