# PA² ver1_09 소스

최신 애플리케이션의 전체 소스·테스트·문서·빌드 설정을 소스 ZIP으로 제공합니다.

- [소스 ZIP 다운로드](PA2_ver1_09_full_source.zip?raw=true)
- [SHA-256](PA2_ver1_09_full_source.zip.sha256)
- [포장 및 검증 결과](PA2_ver1_09_full_source.zip.report.json)

압축 해제 후 PA2_ver1_09_source/SOURCE_README_KO.txt를 확인하세요.
개발 환경은 Windows x64 및 Python 3.13 x64입니다.

## 최신 기능

- 부품 트리에서 색상 칸을 클릭해 그룹 전체 또는 하위 바디의 색상을 편집합니다.
- 개별 색상을 프로젝트에 저장하며 그룹화·해제·재열기 후에도 유지하고 조립 영상에 반영합니다.
- 마우스 회전 시 고정 시점의 선택을 해제해 등각 등 원하는 시점을 다시 선택할 수 있습니다.
- 다중 선택의 수정 항목을 일괄 적용하고, 가장 앞선 단계만 미리봅니다.
- STEP 내부 트리·하위 바디 표시와 숨김, 복구 모델의 수동 작업, 공유 관리 데이터 제거를 지원합니다.

## 소스 구성

애플리케이션 Python 모듈 112개와 테스트·문서·빌드 및 DB 스키마 설정,
아이콘·로고·영상 템플릿·Noto Sans KR 글꼴을 포함합니다.
공개 저장소의 기존 정책에 따라 CAD·프로젝트 DB·로그·영상·학습 데이터·assets/pilot 번들,
실행 파일·개발 환경·빌드 결과를 제외합니다.
별도 모델 번들이 없는 소스 빌드는 기존 규칙을 사용합니다.
사내 실행 배포본에는 승인된 순서·방향 모델이 포함됩니다.

## 검증

- 소스 ZIP CRC 및 파일별 해시 검증을 통과했습니다. 파일 수는 385개입니다.
- 압축 해제한 소스에서 603개 테스트가 통과했고 2개는 건너뛰었습니다.
- 별도 모델 번들이 필요한 bootstrap 관련 테스트 3개를 제외했습니다.
- 실행 배포본의 압축 해제 EXE에서 GUI 검사 94개를 통과했습니다.
- 색상 관련 검사 19개와 수동 회전 시점 검사 2개를 포함합니다.
- SOURCE_MANIFEST.json에 파일별 해시 및 대응 실행 파일·사내 배포 ZIP 해시가 있습니다.

개발 검증에는 격리된 PA2_DATA_ROOT·PA2_INSTALL_ROOT를 사용하고 PA2_DISABLE_BACKGROUND_LEARNING=1을 설정하세요.
기존 상세 기술 명세는 당시 이력이며 최신 기능은 docs/RELEASE_VER1_09.md와 현재 코드를 함께 확인하세요.
