PA² ver1_04 전체 소스 전달 안내
작성일: 2026-10-26

1. 이 압축파일의 용도
최신 ver1_04 프로그램을 수정하기 위한 개발용 소스입니다.
사용자 실행용 PA2_ver1_04_windows_x64.zip과는 다릅니다.
실행용 ZIP은 Python 설치가 필요 없지만, 이 소스에서 실행/빌드하려면
Windows x64, Python 3.13 x64 및 requirements-lock.txt의 라이브러리가 필요합니다.
라이브러리 설치 시 인터넷 연결이 필요하며, 오프라인 설치용 wheel은 포함하지 않습니다.

포함: src 전체(UI/알고리즘/저장/영상/학습/로그/제거), 아이콘·템플릿,
학습된 순서/방향 모델, 모델 운용용 학습·평가 참조 JSON 및 평가 BREP,
DB 마이그레이션·스키마, 테스트, 개발/진단 도구, 빌드 설정, 기술 문서.
제외: 가상환경, EXE/DLL 등 빌드 결과물, 기존 배포 ZIP, 실제 사용자 프로젝트
DB·작업 로그·생성 영상, runtime-data의 실험 결과 및 외부 원본 STEP.
assets/pilot의 BREP은 배포 모델의 고정 평가 리소스이므로 포함되어 있습니다.
외부 원본 STEP이 없으면 그것을 사용하는 통합/과거 검증 도구는 별도 자료가 필요합니다.

2. 먼저 읽을 문서
이 안내가 소스 전달/환경 구성의 시작점입니다.
현재 기능 기준: docs/PA2_ver1_04_상세_기술명세.md
정확도·알고리즘 로그 운영: docs/ACCURACY_LOG.md
모델·로그·제거 운용: V28_OPERATIONS.md
README.md 및 docs의 이전 vXX 결과는 원본 그대로 보존한 변경 이력입니다.
이전 문서의 구버전 기본값·미구현 설명보다 ver1_04 상세 명세를 우선하세요.
성능 요약 로그에 대해서는 위 ver1_04 추가 문서와 V28_OPERATIONS.md를 우선하세요.
log/accuracy_log에 성능 숫자와 허용된 알고리즘 정보를 기록하며 실제 사용자 로그는 이 ZIP에 없습니다.
기존 상세 로그 추출 도구 tools/export_accuracy_logs.py와 관련 테스트도 포함합니다.
이번 소스 ZIP에는 순서/방향별 실제 LGBMRanker 사용·성공 예측 횟수·복귀 여부,
알고리즘 버전, 형상 최적화 활성화/실제 적용 기록까지 포함한 최신 코드가 들어 있습니다.
프로젝트/모델 ID를 외부 요약에 내보내지 않는 코드와 검증 테스트도 포함합니다.

명세 원문 보존 및 같은 1_04 이름의 갱신 주의:
첨부한 상세 명세는 작성된 원문 그대로 포함했습니다. 명세 15.4절과 부록 B의
'기존 전체 소스 ZIP'은 이 소스 재포장 이전의 1_04 전달본 상태와 과거 해시입니다.
그 뒤 사용자 요청으로 본 전체 소스 ZIP을 최신 코드와 명세로 다시 만들었습니다.
현재 소스 파일별 해시는 SOURCE_MANIFEST.json, 현재 ZIP 해시는 ZIP 옆 .sha256이 기준입니다.
현재 대응 실행용 ZIP의 SHA-256은 다음과 같습니다:
  3ff2f535175992985faecd02d01344f13b5df40a2433d2424bf16180eb665d2a
SOURCE_MANIFEST.json의 paired_runtime으로도 대응 EXE/배포본을 식별할 수 있습니다.
이 소스 재포장으로 실행용 ZIP이나 프로그램 실행 파일은 변경하지 않았습니다.
문서와 과거 검증 스크립트의 절대 경로는 원 개발 PC 기준이므로 필요 시
본인의 경로로 지정해야 합니다. 원본 소스는 이 전달 과정에서 변경하지 않았습니다.

3. 개발 환경 구성 (PowerShell, 압축 해제한 소스 최상위 폴더에서)
  powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1

Python을 자동으로 찾지 못하면:
  powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -Python "C:\경로\python.exe"

setup.ps1은 .venv를 만들고 requirements-lock.txt 및 편집 가능한 패키지를 설치합니다.
pyproject.toml의 내부 패키지 버전 0.1.0은 그대로이며 배포판 표기는 ver1_04입니다.

4. 기존 업무 데이터와 격리하여 소스 실행 (같은 PowerShell 세션에서)
  $env:PYTHONPATH = Join-Path $PWD.Path 'src'
  $env:PA2_DATA_ROOT = Join-Path $PWD.Path 'runtime-data\developer'
  $env:PA2_DATABASE_URL = 'sqlite:///' + (Join-Path $PWD.Path 'runtime-data\developer\database\pa2.sqlite').Replace('\','/')
  $env:PA2_INSTALL_ROOT = $PWD.Path
  $env:PA2_DISABLE_BACKGROUND_LEARNING = '1'
  New-Item -ItemType Directory -Force -Path (Join-Path $env:PA2_DATA_ROOT 'database') | Out-Null
  .\.venv\Scripts\python.exe -X utf8 .\run.py

업무용 EXE와 소스 실행의 기본 저장소는 같을 수 있습니다. 위 환경변수로 반드시
개발 데이터를 분리하세요. 실제 사용자의 DB를 개발용으로 지정하지 마세요.
PA2_DISABLE_BACKGROUND_LEARNING=1은 GUI 개발 중 자동 백그라운드 학습을 막습니다.
학습 운용 검증은 별도 데이터에서 이 변수를 해제하고 진행하세요.
이 소스에는 업무 DB나 업무 로그가 없으며, 첫 실행 시 개발용 저장소가 생성됩니다.

5. 테스트
위 격리 환경변수를 설정한 같은 PowerShell에서:
  powershell -ExecutionPolicy Bypass -File .\scripts\test.ps1

설치된 의존성을 사용해 tests 전체를 실행합니다. 그래픽 드라이버/네이티브 CAD
런타임이 필요한 검사는 해당 실행 환경이 필요합니다. 외부 STEP에 의존하는 검사는
제공 파일이 없을 때 건너뛰거나 별도 경로 설정이 필요할 수 있습니다.
단순 GUI 수정 시 UI/서비스/알고리즘 연결은 유지하고 변경 후 회귀 테스트하세요.
과거 install_vXX_runtime.ps1, open_validation_vXX.bat, 진단 도구는 원 개발환경의
경로/데이터를 전제할 수 있으니 내용을 확인한 후 사용하세요.

6. EXE 재빌드
개발용 데이터 격리를 유지하고, 기존 배포본이 아닌 이 소스 복사본에서 수행하세요.
  powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1

테스트 성공 후 packaging/pa2.spec으로 PA2.exe와 _internal을 생성/배치합니다.
기존 소스 폴더의 실행 구성은 build/previous-release-*에 보존됩니다.
제거 프로그램은 별도로 빌드합니다:
  .\.venv\Scripts\python.exe -m PyInstaller --noconfirm --distpath build\uninst-distribution packaging\uninst.spec
  Copy-Item -LiteralPath .\build\uninst-distribution\uninst.exe -Destination .\uninst.exe

PA2.exe, uninst.exe, _internal이 모두 준비된 다음 설치 목록을 만듭니다:
  .\.venv\Scripts\python.exe -c "from pathlib import Path; from pa2.uninstaller import inventory; inventory(Path.cwd())"

이 소스 ZIP에는 다른 PC의 제거 경로가 등록되지 않도록 .pa2-install.json을
넣지 않았습니다. 위 목록 생성은 새 빌드가 완료된 복사본에서만 수행하세요.
uninst.exe는 시험용 복사본에서만 검증하고 실제 프로젝트 제거에는 주의하세요.
실행용 ZIP 생성 도구는 tools/package_portable.py이며 --help로 인수를 확인하세요.
배포 시 EXE만 전달하지 말고 _internal 및 설치 목록을 포함해야 합니다.

7. 파일 무결성
SOURCE_MANIFEST.json에 포함 파일별 크기와 SHA-256이 있습니다.
ZIP 옆의 .sha256으로 전달 전후 ZIP이 같은지 확인할 수 있습니다.
전체 소스 재포장 도구는 handoff/package_pa2_full_source.py입니다:
  .\.venv\Scripts\python.exe -X utf8 handoff\package_pa2_full_source.py --project . --version 1_04 --output releases\새이름.zip
기존 ZIP은 덮어쓰지 않습니다. 새 파일 이름을 사용하세요.
