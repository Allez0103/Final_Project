- 고정 평가 E01~E05는 학습에 넣지 않습니다. 계열별 가중치와 동시 작업의 동률을 유지합니다. 저비용 선호 검사 후 유망한 후보에만 실제 CAD 비교를 수행하고, 안전·선호·시간·검사 수 기준을 모두 만족할 때 자동 교체합니다. 개선이 없는 완료 주기도 처리한 10개를 집계 완료하고 다음 신규 프로젝트를 기다립니다. 실패·중단은 집계하지 않습니다.

## 로그

EXE 옆 `log` 폴더에 생성 실행당 JSON 하나를 기록합니다. 최초 초안·설정·시간·검사 수·부품명을 보존하고, 사용자 확정 순서·방향과 비교값을 버전별로 누적합니다. 비교값은 **사용자 확정본과의 유사도이지 물리적 간섭 정확도가 아닙니다.** 확정 전이나 이전 초안이 없는 경우 정확도를 임의로 채우지 않습니다. 학습 주기와 활성화·복귀 이벤트는 별도 JSON입니다. 로그 실패는 경고하고 프로젝트 저장은 유지합니다. 상위 설치 폴더에 쓰기 권한이 필요합니다.

2026-10-26: `log/accuracy_log`에 외부 공유용 숫자 성능 요약을 별도로 기록합니다. 프로젝트/부품/모델 식별자·실제 순서/방향·원문·경로·시각은 포함하지 않습니다. 생성 시간·검사 수·단계 수와 확정본 대비 유사도만 허용 목록으로 추출합니다. **외부에는 이 하위 폴더의 JSON만 전달하고 상위 상세 로그는 전달하지 마세요.** 기존 기록 추출 및 보안상 한계는 `docs/ACCURACY_LOG.md`를 확인하세요.

## 제거

`uninst.exe`는 실행 중인 PA² 종료를 요구하고 최종 삭제 경로를 표시한 후 확인을 받습니다. `.pa2-install.json`의 프로그램 파일과 앱 실행 시 `.pa2-owned.json`으로 등록한 관리 프로젝트·DB·관리 자산 사본·캐시·작업·학습·로그·설정만 삭제합니다.

외부 원본 STEP, 제공 파일, 소스, 실험 보고서, 미등록 파일은 삭제하지 않습니다. 변경된 실행 구성 파일은 보존합니다. 다른 설치와 공유하는 데이터, 정션·심볼릭 링크, 광범위 경로, 잘못된 명세는 삭제를 거부합니다. 등록 전 제거하면 사용자 데이터는 제거하지 못하므로 PA²를 한 번 실행해 등록해야 합니다. 권한 문제나 잠긴 파일이 있으면 일부가 남을 수 있으며 결과 안내 후 재시도해야 합니다. 삭제된 관리 프로젝트는 복구가 보장되지 않으므로 필요한 프로젝트는 먼저 별도 백업하세요.

빌드: 기존 `packaging/pa2.spec`로 PA2를 만들고 `packaging/uninst.spec`로 uninst를 만든 뒤 같은 폴더에 배치합니다. 그 후 `pa2.uninstaller.inventory(설치폴더)`로 정확한 파일 목록을 갱신해야 합니다. `_internal`과 manifest를 포함한 전체 폴더를 전달해야 하며 EXE만 복사하면 안 됩니다.
