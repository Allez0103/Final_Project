PA² 사내 사용 안내 — ver1_04 (2026-10-26)

1. ZIP 파일을 PC의 쓸 수 있는 폴더에 전부 압축 해제합니다.
2. PA2_ver1 폴더 안의 PA2.exe를 실행합니다.
3. PA2.exe 옆의 _internal 폴더는 옮기거나 이름을 바꾸지 않습니다.

Windows 64비트용 프로그램입니다. Python을 별도로 설치할 필요는 없습니다.
압축 파일 내부에서 EXE만 실행하거나 EXE 하나만 따로 전달하지 마세요.
프로그램을 다른 폴더로 옮길 때는 PA2_ver1 폴더 전체를 함께 옮기세요.

처음 사용할 때
- 프로젝트 화면에서 새 프로젝트를 만들고 완제품 STEP 및 부품 파일을 선택합니다.
- 작업 속성에서 기준 부품과 필요한 예외 부품을 지정합니다.
- 필요하면 부품을 Ctrl/Shift로 다중 선택해 그룹화한 뒤 순서를 생성합니다.
- 부품 목록과 순서 카드에서 여러 개를 선택하면 선택 부품은 빨간색,
  나머지는 회색·투명도 90%로 표시됩니다. 단일선택의 나머지 부품은
  투명도 75%입니다. 직접 숨긴 부품은 선택만으로 다시 나타나지 않습니다.
- 부품 목록이나 3D에서 단일선택한 부품을 다시 일반 클릭하면 선택이 해제됩니다.
- 그룹명은 직접 입력하거나 선택한 부품의 이름 중에서 고를 수 있습니다.
- 자동 그룹은 해제할 수 없고, 수동 그룹만 그룹해제로 되돌릴 수 있습니다.
- 그룹 구성을 바꾸면 순서를 다시 생성해야 합니다.
- 자동생성 또는 수동생성으로 초안을 만들고 카드 순서, 조립 방향과 카메라를
  확인합니다. 수동생성은 일반 부품의 경로 검사를 생략해 빠르게 시작합니다.
- 순서 카드의 다중선택으로 여러 단계를 묶어 이동할 수 있습니다.
- 작업 속성의 미리보기로 선택한 과정의 움직임을 확인할 수 있습니다.
- TOP 및 AUTO의 실제 탑뷰는 원래 모델의 긴 쪽이 화면 가로에 오도록
  자동 정렬합니다. 화면 회전 0°가 자동 정렬 기준이며, ↶/↷ 90° 버튼은
  여기에 사용자 회전을 더합니다. 실제 부품과 조립 방향은 바꾸지 않습니다.
- 수정값을 선택 단계에 적용하고 ‘순서 확정’ 후 ‘영상 생성’을 누릅니다.
- 확정 뒤 다시 수정하면 재확정해야 하며, 간섭 검사를 다시 하지 않습니다.
- 영상 재생에서 5초 앞/뒤 이동, 0.25~4배속, 전체화면을 지원합니다.
  전체화면은 Esc로 해제할 수 있습니다. 부품 이동/점멸 시간은 설정에서
  변경할 수 있습니다. 기본값은 이동 0.7초, 이동 전 점멸 2초입니다.
- 이번 영상 시점·템플릿 개선은 새로 생성한 영상에 적용됩니다.
  이미 저장되거나 내보낸 기존 MP4는 자동으로 변경하지 않습니다.
- 영상 화면의 ‘최신 버전만 남기기’는 현재 프로젝트의 정상 완료 영상 중
  최신 한 개만 보존합니다. 이전 완료 영상은 삭제되며 되돌릴 수 없습니다.
  다른 프로젝트, 별도로 내보낸 복사본, CAD와 순서 데이터는 삭제하지 않습니다.

자동 초안은 사용자 검토 후 확정하는 구조입니다. 볼트·너트는 별도 경로
간섭 검사 없이 방향을 지정합니다. 사용자 편집과 영상 재생성도 경로를
재검사하지 않으므로, 최종 작업 순서와 영상은 담당자가 확인해 주세요.

데이터 위치
기본적으로 각 직원 계정의 %LOCALAPPDATA%\THN\PA2에 저장합니다.
개발자의 기존 CAD, 시험 프로젝트, 시험 영상은 이 ZIP에 포함하지 않았습니다.
프로그램 폴더와 직원별 작업 데이터 폴더는 서로 다릅니다.

이번 버전의 모델과 로그
- 평가 완료한 순서·방향 모델과 학습 참고 자료가 포함되어 있습니다.
  처음 실행하면 모델을 설치하며, 기존 활성 모델과 사용자 설정은 유지합니다.
- 초기 적용 이후 변형 제품을 포함한 신규 완전 확정 프로젝트 10개마다
  유휴 시간에 재학습합니다. 같은 프로젝트의 재확정은 추가 집계하지 않습니다.
  평가를 통과한 경우에만 모델을 교체하며, 개선이 없으면 기존 모델을 유지합니다.
- EXE 옆 log 폴더에 생성 시간, 검사 수, 최초 초안과 확정 이력을 기록합니다.
  확정본과의 유사도는 실제 간섭 정확도를 의미하지 않습니다.
  프로그램 폴더에도 쓰기 권한이 있어야 합니다.
- log/accuracy_log에는 외부 공유용 성능 요약 JSON을 별도로 기록합니다.
  순서·방향 유사도, 생성 시간, 검사 수, 단계 수만 허용 목록으로 추출하며
  프로젝트/부품명·내부 ID·실제 순서/방향·경로·오류/입력 원문·시각은 제외합니다.
  외부에는 이 하위 폴더의 JSON만 전달하세요. 상위 log 전체는 보내지 마세요.
  부품 수·시간 등의 통계도 회사 반출 규정에 따라 공유해야 합니다.
  생성 시 작성하고 확정/재확정하면 같은 파일에 비교 이력을 누적합니다.
  확정 전이나 최초 초안이 없는 이전 프로젝트는 비교 불가로 표시합니다.
- 성능 요약의 algorithms에는 순서/방향 추천이 규칙 기반인지 LGBMRanker인지,
  알고리즘 버전, 성공 예측 횟수와 오류 복귀 여부, 형상 최적화 활성화/실제 적용
  여부를 기록합니다. 프로젝트/모델 ID는 포함하지 않습니다. 과거 기록에서
  확인할 수 없는 항목은 미상으로 남기며 현재 설정으로 추정하지 않습니다.
- 이번 ZIP은 기존 사용자 프로젝트·영상·상세 로그·성능 요약 로그를
  포함하지 않습니다. 압축 해제 시 log/accuracy_log는 비어 있습니다.
- 자세한 운영 정책은 V28_OPERATIONS.md를 참고하세요.
  외부용 요약의 항목 및 주의사항은 docs/ACCURACY_LOG.md에 있습니다.

프로그램 제거
- PA²와 계산 작업을 모두 종료한 뒤 같은 폴더의 uninst.exe를 실행합니다.
- 최종 확인 후 프로그램과 등록된 관리 프로젝트·DB·관리 자산 사본·캐시·
  학습·로그·설정을 삭제합니다. 필요한 프로젝트는 먼저 별도 백업하세요.
- 외부 원본 STEP과 미등록 파일은 삭제하지 않습니다. 다른 설치와 공유하는
  데이터나 정션·링크 경로는 자동 삭제하지 않습니다.
- 처음 실행하기 전에는 사용자 데이터가 등록되지 않으므로 해당 데이터는
  제거되지 않습니다. 설치 관리 파일 .pa2-install.json도 함께 보관하세요.

이번 묶음은 사내 전달·실행 확인용입니다. 배포 담당 PC에서는 압축을 푼
패키지의 창 실행, CAD 계산, 영상 인코딩을 확인했습니다. 별도 수신 PC에서의
검증은 수신 PC에서 진행해야 합니다. EXE에는 전자서명이 적용되지 않았습니다.
라이브러리 고지와 실제 FFmpeg 구성은 THIRD_PARTY_NOTICES 및 라이선스 목록을
참고하세요. 외부 공개·납품용의 라이선스 검토 완료를 뜻하지 않습니다.
