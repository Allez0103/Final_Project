# v19 기능 변경

## 영상 생성과 확정

- ‘재검토’를 제거하고 ‘영상 생성’으로 통합한다. ‘순서 확정’은 유지한다.
- 적용하지 않은 작업 속성 값이 있으면 먼저 선택 단계에 적용해야 한다.
- 순서·방향·거리·카메라·문구 변경 후에는 재확정해야 영상 생성이 가능하다.
- 확정본은 불변 사본이다. 저장·재열기 후에도 현재 초안과 확정본의 내용이 일치하는지 비교한다.
- 사용자 편집·확정·영상 재생성에는 CAD 접촉·경로 재검사를 추가하지 않는다.

## 수동 그룹

- 부품 목록에서 Ctrl/Shift로 두 개 이상을 선택해 ‘그룹화’한다. 기준 부품은 먼저 다른 부품으로 바꿔야 묶을 수 있다.
- 그룹 이름은 직접 입력하거나 **선택한 부품의 이름만** 담긴 목록에서 선택한다. 그룹 창에는 분해 방향 필드가 없다.
- 그룹은 3D 모델·부품 목록·순서 카드·영상에서 하나의 이동 단위다. 방향과 거리는 이후 순서 생성이 결정한다.
- 파일 분석으로 만든 자동 그룹은 항상 하나의 부품으로 표시하며 해제할 수 없다. 수동 그룹에 포함하더라도 자동 그룹의 내부 바디는 분해하지 않는다.
- ‘그룹해제’는 사용자가 만든 수동 묶음만 풀며, 중첩 수동 그룹은 한 겹씩 복원한다.
- 변경마다 새 그룹 스냅샷을 저장한다. 현재 순서·확정 포인터는 초기화하고 순서 재생성을 요구한다. 이전 스냅샷·확정 기록·영상은 보존한다.
- 바디 중복·누락을 차단하고, 기존 접촉 그래프는 외부 관계만 합산한다. 해제하면 원래 관계를 복원한다. 간섭 판정 허용 기준은 바꾸지 않는다.
- 예외 지정 부품을 포함한 묶음은 그룹 전체에 예외가 적용된다. 해제 시 원래 예외 부품을 복원한다. 묶은 뒤 새로 그룹에 예외를 지정했다면 해제된 구성원 모두에 적용한다.

## 최신 버전만 남기기

- 영상 화면의 버튼으로 **현재 프로젝트 관리 영역**의 최신 정상 완료 MP4 한 개를 남긴다. 최신은 파일 수정 시각 기준이다.
- 해당 프로젝트의 확정 ID에 속하는 정상 게시 영상만 정리한다. 실제 FFmpeg로 끝부분 프레임을 읽어 정상 완료 여부를 확인한다.
- 생성 중 임시 파일, 실패·손상 파일, 소유 관계가 없는 파일, 다른 프로젝트, 별도로 내보낸 복사본은 삭제하지 않는다.
- 경로 이탈·링크·작업 중 파일 변경을 확인한다. 남길 최신 영상의 상태도 삭제 직전에 다시 확인한다.
- 삭제 전 재생기를 멈추고 파일을 해제한다. 삭제 후 개수와 확보 용량을 표시하며 최신 영상을 다시 연다. 삭제는 되돌릴 수 없다.

## 변경하지 않은 사항

볼트 머리 쪽 축방향 배치, 일반 부품 우선 탐색, 초기 겹침 감소 정책과 간섭 판정 기준은 유지한다. 예외 부품만 제외한 부분 학습 데이터 저장은 추후 고도화 항목이며 이번에는 구현하지 않았다.
