## 3. 계산 방식의 한계가 재현된 12개

모두 `ConservativePathChecker._swept_check()`의 유효성 검사에서 다음 상태가 재현됐다.

```text
prism.IsDone() = True
솔리드 존재 = True
BRepCheck_Analyzer(swept).IsValid() = False
→ PATH_UNKNOWN
```

실패 위치는 `src/pa2/cad/path_check.py:294`다. 원본 부품이 아니라 부품의 면을 이동시켜 만든 검사 체적(sweep)이 유효하지 않은 것이다. 현재 구현은 평면의 접선 이동과 원통의 축 이동만 별도 처리하고, 원뿔 및 축에 비평행한 원통면 등의 일반 sweep은 유효하지 않을 때 UNKNOWN으로 끝낸다. 시간 제한을 늘리는 것만으로 해결된다는 근거는 없다.

## 해결 검토의 우선순위 — 이번에는 변경하지 않음

1. 원뿔면·비축 원통면 등 곡면의 연속 경로 검사 방식을 보완한다. 단순히 UNKNOWN을 PASS로 바꾸면 안 된다.
2. 커버-씰의 의도된 압축/체결 여부와 분리·동시 이동 방식을 확인한다. 커버는 내부 볼트 13개에 영향을 주는 우선 병목이다.
3. 너트 4개와 미분류 바디 45~48의 부품 정체 및 체결 관계를 확인한다. 현재 볼트 예외는 이들에 적용되지 않는다.
4. 커넥터·블록·미분류 그룹의 초기 겹침을 각각 평가하고, 필요한 경우에만 한정된 정책을 정한다.

현재 지지 미검증은 이미 검토용 초안에 허용되어 있으므로 이번 44개의 직접적인 차단 원인은 아니다. 기존 탐색은 제한된 방향·후퇴 예산으로 수행됐으며, 이번 조사도 물리적으로 가능한 모든 조립 방법이 없다는 증명은 아니다.
