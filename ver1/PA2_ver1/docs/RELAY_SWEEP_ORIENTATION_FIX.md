# 릴레이 이동 검사 형상 방향 수정

이전 릴레이 +Z 진단의 작은 BSpline 면을 동일한 관리 캐시와 이동 거리 139.20000010045698 mm에서 재현했다. CAD 사본의 보정 허용 기준과 간섭 허용 기준은 유지했다.

| 항목 | 수정 전 | 수정 후 |
|---|---:|---:|
| 검사 솔리드의 부호 있는 체적 | 약 -0.0884396934 mm³ | 약 +0.0884396934 mm³ |
| 무한점 분류 | 내부 IN | 외부 OUT |
| MBD-KD000과의 교차 체적 | 1,191,328.417649351 mm³ | 0 mm³ |

RLY-KET400 #1과 #2 모두 같은 결과다. 수정 전 솔리드는 BREP 유효성 검사를 통과하면서도 의도한 작은 유한 영역의 바깥쪽을 내부로 표현했다. 따라서 작은 검사 형상과 본체를 교차했는데도 본체 전체 체적이 반환되었다.

`valid_prism()`은 새로 생성한 검사 형상의 솔리드가 하나인지 확인하고, 무한점이 내부이면 그 형상의 방향을 반전한다. 이후 무한점 외부, 양의 유한 체적, BREP 유효성을 모두 확인한다. 실패하면 기존 보수적 대체 경로로 넘어가며 PASS로 처리하지 않는다. 입력 CAD 면이나 원본 파일은 변경하지 않는다.

수정 전후 실제 릴레이 근거:

- `runtime-data/native-validation/relay-sweep-orientation-v2.json`
- `runtime-data/native-validation/relay-sweep-orientation-v14.json`
- `runtime-data/native-validation/relay-sweep-orientation-v14-final.json` (최종 버전 표기 포함 재현)
- 재현 도구 `tools/probe_relay_sweep_orientation.py`

v14 파일의 `original_sweep` 필드는 현재 생성기의 출력이고 `reversed_copy_sweep`는 비교를 위해 의도적으로 다시 뒤집은 사본이다. 앞선 진단 도구의 문구보다 수치·버전·위 필드 의미를 기준으로 읽는다.

이 재현은 문제가 된 면의 잘못된 충돌을 해소했다는 근거다. 릴레이 전체의 모든 면·다른 부품과의 전체 이동 경로 통과는 별도 전체 실행 결과에서 확인한다.

합성 회귀시험은 면의 정·역방향과 ±Z 이동의 네 조합에서 무한점 OUT 및 기대 체적을 확인한다. 기존 얇은 장애물·실제 충돌·미판정 시험도 유지한다.
