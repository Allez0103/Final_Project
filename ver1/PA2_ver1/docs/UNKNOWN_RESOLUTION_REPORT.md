## 원인과 수정

초기 겹침 허용은 출발점의 겹침만 처리합니다. 이전 `path-v4-initial-region`은 이동 경로를 만드는 곡면 prism이 유효하지 않으면 즉시 UNKNOWN으로 반환했습니다. 따라서 초기 겹침 차단을 제거해도 다른 이유로 같은 20단계에 머물렀습니다.

이전 최종 잔여 상태의 미판정 포함 35그룹에서 각각 대표 UNKNOWN 방향·장애물 쌍 1개를 재현했습니다. 모든 방향을 대표하는 완전한 충돌 진단은 아니며, 아래는 같은 35쌍의 비교입니다.

| 원래 실패한 면 | 대표 쌍 수 | 부품 |
|---|---:|---|
| 원뿔 | 12 | BLT-WASM612A 4개, NUT 4개, source 바디 41~44 |
| 원통 | 17 | BLT-WASM620R #11~23, BUS-KD300, LV CONT, source 바디 1·2 |
| 토러스 | 6 | COV-KD000, SEL-KD000, source 바디 45~48 |

35개 중 31개는 입력 형상 정밀 검사에 통과했지만 이동 영역 생성에서 실패했습니다. BLT-WASM612A 4개는 입력 BREP 자체가 위상 검사에는 통과하고 기하 정밀 검사에는 실패했습니다. 기존 수입기의 `geometry_valid`는 위상 중심 검사이므로 이것만으로 정밀 Boolean의 성공을 보장하지 못했습니다.

`path-v7-curved-sweep` 수정:

1. 장애물과 만날 수 없는 면은 보수적 경계 상자로 제외합니다. 원통·원뿔의 실패한 prism은 투영 윤곽과 사분면 경계에서 면을 나누어 다시 검사합니다.
2. 잘린 면의 UV 직사각형이나 토러스 패치의 swept AABB는 실제 면보다 큰 영역입니다. 이 **덮개가 모두 비어 있으면** 경로를 증명할 수 있지만, 덮개가 겹친다는 이유만으로 실제 충돌이라고 하지 않습니다. 불확실한 면 하나에서 즉시 중단하지 않고 다른 면의 실제 충돌 근거도 검사합니다.
3. 연속 영역 검사로 증명하지 못하면 실제 이동 형상 위치에서 추가 충돌 증거를 찾습니다. 이 위치 검사는 BLOCKED의 근거로만 쓰며, 몇 개 위치가 비었다고 PASS로 판정하지 않습니다.
4. 초기·경로 Boolean은 NonDestructive 모드로 호출합니다. 유효하지 않은 입력은 계산용 깊은 사본에 한해 곡선 파라미터 정합성 보정을 시도합니다. 보정 후 기하 유효성, 최대 허용오차와 경계 변화 ≤ 설정 epsilon, 동일 위상 개수, 체적 변화 ≤ max(1e-9 mm³, 원래 체적×1e-8)를 모두 만족해야 사용합니다. 실패하면 UNKNOWN을 유지합니다.
5. 구체적인 미판정 코드, native 오류, 보정 수치·관련 부품을 결과와 GUI 진단에 표시합니다. 보정이 관여한 채택 단계는 검토 경고를 남기며 계획은 REVIEW_REQUIRED입니다.
6. 시작 경계 상자가 분리된 미해결 쌍에는 5초 예산의 연속 거리 구간 검사를 추가합니다(구간 진입 시 예산 확인; 진행 중인 native 호출에는 상위 native·후보·전체 제한 적용). 단위 속도 병진의 거리는 1-Lipschitz이므로, 중점 거리 > 구간 반길이+epsilon인 구간 전체가 비어 있음을 증명합니다. 모든 구간을 증명해야 PASS이며 시간·최소 구간 제한에 걸리면 UNKNOWN입니다. NUT #2 대표 쌍은 이 방법으로 통과했습니다.

초기 허용 영역 `O' = O \ M(0)`, 전체 이동 검사, 원래 장애물과 종점 분리는 유지합니다. 새로운 간섭이나 UNKNOWN을 무조건 허용하지 않습니다. 참고: [OCCT 비파괴 Boolean API](https://occt3d.com/dev/doc/refman/html/class_b_rep_algo_a_p_i___builder_algo.html).

## 추가 발견: 텍스트 BREP 저장·복원 문제

잔여 릴레이를 원본 STEP과 비교하자 텍스트 BREP round-trip에서 일부 바디의 위상 유효성이 깨지는 문제가 재현됐습니다. 원본 STEP을 현재 커널로 읽은 해당 4바디는 위상 유효이며, 텍스트 저장·복원 후에는 4개 모두 위상 무효, 바이너리 저장·복원 후에는 4개 모두 위상 유효입니다. 다만 STEP에서 직접 읽은 형상에도 현재 커널의 정밀 기하 검사 실패가 일부 있으므로 "모든 정밀 검사가 정상"이라는 뜻은 아닙니다. 이는 물리적 제품 불량이나 원본 CAD 손상을 단정하는 판정이 아닙니다.

`path-v8-binary-curved-sweep`에서는 캐시와 native worker 전달 사본을 바이너리 BREP로 변경했습니다. 기존 텍스트 캐시는 보존하고, 새 버전 캐시가 없으면 외부 참고자료 대신 앱의 불변 관리 STEP 사본으로 재생성합니다. 기존 스냅샷과 바디 ID 집합이 다르면 자동 적용하지 않습니다. 접촉 그래프도 새 버전으로 다시 검사합니다. 이전 캐시를 바탕으로 만든 원인 수치·대표 쌍 진단은 위의 v7 중간 결과로 보존합니다.
