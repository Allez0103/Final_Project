# v17 보완 내역

이 문서는 이번 수정 범위다. 실제 성능과 검증 상태는 END_TO_END_V17_RESULT.md와 각 JSON 기록을 기준으로 한다.

## 순서·형상

- 미매칭 유일 후보에만 적용하는 AIR-BENT 그룹화 보완을 포함한다. 실제 실행에서는 LV CONT, HVSC 2800 #1/#2, AIR-BENT0A를 예외로 지정한다.
- 일반 부품만 탐색하고 볼트·너트를 연결된 부품 앞에 삽입하는 분해 구조를 유지한다. 조립은 역순이다.
- 동일 부품 쌍·이동 위치의 유효한 교집합 체적을 native worker 안에서 재사용한다. 형상, 상대 형상, 이동 벡터가 다른 계산은 구분한다. 실패·비유한 값은 재사용하지 않는다.
- 재사용 항목은 실제 형상 핸들을 보유하고 IsEqual로 동일성을 확인한다. 해시 충돌을 인위적으로 만든 시험에서도 서로 다른 형상의 체적을 재사용하지 않는 것을 검증한다.
- 강체 평행이동은 원본을 수정하지 않는 위치 변환으로 수행해 불필요한 형상 복사를 줄인다. Boolean은 NonDestructive 모드를 유지한다.
- 교집합 결과가 무효일 때 인자 순서를 바꿔 재계산하고 기존 제한의 매개변수 보정을 시도한다. 재시도 근거를 common_retries에 보존하고 실패는 UNKNOWN으로 유지한다.
- BLK-KD000의 14.5mm −X 교집합 오류를 실제 형상으로 재현했다. 역순·솔리드 분할·옵션 변경으로 해결되지 않았다. 일반 ShapeFix는 유효한 결과를 만들지만 체적이 달라져 무조건 채택하지 않았다. 최종 잔여 판정은 전체 실행 보고서에 기록한다.
- OCCT Boolean 스레드 수를 설정할 수 있다. 실제 형상 6개 연산을 1/2/4스레드로 두 번씩 비교한 결과 4스레드가 가장 빨랐고 유효성·체적이 일치해 기본 상한을 4로 설정했다. 동시 CAD 프로세스 수는 늘리지 않았다.
- 간섭 epsilon, 초기 겹침 감소 기준, 입력 보정 허용기준은 유지한다.

## 편집·미리보기

- 작업 속성에 ‘미리보기’ 버튼을 추가했다. 선택한 단계의 입력 중인 방향·거리·카메라를 임시 계획에 적용해 최종 영상과 같은 시간축으로 재생한다.
- 재생·중지·종료 후 카메라, 부품 위치·표시·색상을 복원한다. 미리보기는 초안과 입력값을 확정하거나 CAD 검사를 실행하지 않는다.
- 순서 카드 썸네일은 보이는 카드부터 순차 생성하고 생성 결과를 재사용한다.
- 과정 문구 일괄 적용 후 실행 취소 버튼이 즉시 갱신된다.
- 작업 중 프로젝트 전환을 상태 변경 전에 차단하고 계산·렌더의 입력 프로젝트를 고정한다.
- 프로젝트 화면은 작업 중 비활성화하며, 새 프로젝트 불러오기·재열기가 성공한 뒤에만 현재 프로젝트를 교체한다. 실패해도 기존 모델과 프로젝트가 어긋나지 않는다.
- 새 순서 확정 시 이전 영상·내보내기 상태를 초기화해 새 영상 생성 필요 상태를 표시한다.

## 카메라·영상

- 시선과 위쪽 축을 함께 quaternion 보간해 기존 ViewUp 임계값 전환의 급격한 롤을 제거한다. 고정 부품 중심·거리·화각을 유지한다.
- 영상 시간축을 한 번 생성하고 템플릿·로고·문구를 재사용한다. 3D 장면은 매 프레임 갱신한다.
- FFmpeg stderr를 파일로 받으며 watchdog으로 파이프 쓰기 지연·취소·마무리 시간을 감시한다. 실패 시 프로세스 종료·wait 후 임시 파일을 정리한다.
- 인코더를 자동/CPU/NVIDIA/Intel/AMD로 선택할 수 있다. 실제 구동 가능 여부를 시험하고 자동 모드는 시험 소요시간을 기준으로 선택한다. 미지원 요청은 CPU로 대체하고 실행 도중 하드웨어 인코더가 실패하면 같은 전체 시간 예산 안에서 CPU로 재시도한다.
- GPU는 영상 인코딩 옵션이며 정밀 CAD 계산은 CPU를 사용한다. VTK 렌더링 장치는 실제 실행에서 별도 기록한다.
- 이동 전 점멸·이동 중 하이라이트, 품명 자재정보, 사용자 입력 주의사항, 빈 패널 템플릿, 진행도·배속·전체화면·Esc 해제를 유지한다.

## 저장·배포

- native BREP 쓰기 전에 디렉터리 생성·쓰기 가능 여부를 확인한다.
- 승인된 아이콘 PNG를 다중 해상도 ICO로 변환했다. PA 흰색, 위첨자 2 노란색이며 EXE·창·작업표시줄에 적용한다.
- 배포 위치는 ver1/PA2/PA2.exe다. 의존 파일은 같은 폴더의 _internal에 포함한다.
- open_validation_v17.bat로 이번 검증 데이터 폴더를 사용하는 배포본을 연다. 기존 v16 결과와 제공 원본은 보존한다.
