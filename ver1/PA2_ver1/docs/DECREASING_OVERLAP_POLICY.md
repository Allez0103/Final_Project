# 초기 겹침 감소 예외 — v10 검토용

사용자 요청에 따라 모든 부품 초기 겹침 예외가 켜져 있을 때 기본 정책을 고정 공간 예외에서 **위치별 겹침 감소 예외**로 변경했습니다. 이전 고정 공간 정책은 설정의 `initial_overlap_decrease_enabled`를 끄면 사용할 수 있습니다. 모든 초기 겹침 예외를 끄려면 `initial_overlap_region_enabled`와 `bolt_initial_overlap_enabled`를 끕니다.

## 판정

1. 정밀 형상 검사에 통과한 부품 쌍의 초기 교차 부피를 계산합니다. 초기 겹침이 없는 쌍은 기존 연속 이동 영역 검사를 그대로 사용합니다. 입력 무효·Boolean 실패·시간 초과를 통과시키지 않습니다.
2. 초기 겹침이 있는 쌍만 0.01, 0.05, 0.1, 0.25, 0.5 mm 위치와 그 이후 최대 0.5 mm 간격으로 검사합니다. 이동 거리가 짧으면 실제 종점에서 끝냅니다. 최대 256위치 및 기존 후보/native/전체 시간 제한이 적용됩니다.
3. 교차 부피가 **지금까지의 최저값**보다 `max(epsilon³, 초기 부피 × 1e-6)` mm³를 초과해 증가하면 `OVERLAP_REINCREASE`로 차단합니다. 직전 값만 비교하여 작은 증가가 누적되는 것을 허용하지 않습니다. 평탄 구간은 허용하지만 최종적으로 분리되어야 합니다.
4. 교차 부피가 epsilon³ 이하인 첫 위치부터 **원래 상대 형상**에 대해 남은 경로 전체를 연속 검사합니다. 중간 표면 접촉·미끄럼은 기존 경로 기준으로 검사하며, 양의 간격을 얻으려고 중간 거리 계산을 반복하지 않습니다. 재진입·얇은 장애물도 기존 검사로 차단합니다. 종점은 거리 epsilon을 초과하여 분리되어야 합니다.
5. 검사 위치·부피·허용 오차·분리 위치·후속 연속 검사 결과를 `pair_diagnostics`에 저장합니다. 예외 쌍은 `initial_decrease_exceptions`, 채택 단계 수는 `initial_decrease_exception_steps`로 기록합니다. 캐시 키와 정책 버전을 구분합니다.

## 보장하지 않는 범위

이것은 **연속 감소 증명이 아니라 유한 위치 검사**입니다. 검사 위치 사이의 순간 재증가를 놓칠 수 있습니다. 특히 처음부터 겹친 같은 상대 부품에서 기존 겹침 감소가 다른 위치의 새 충돌 증가를 상쇄할 수 있습니다. 부피 감소는 국소 충돌 없음의 증명이 아닙니다. 실제 씰 변형, 나사 회전, 공구 접근성도 검증하지 않습니다.

따라서 예외 사용 단계는 `INITIAL_DECREASE_EXCEPTION` 또는 지지 미검증 상태에 추가 경고를 붙이며, 전체 순서가 채워져도 `COMPLETE`가 아닌 `REVIEW_REQUIRED`입니다. UI·저장 계획·진단에 이 한계를 표시합니다. 지지 미검증 여부와 초기 감소 예외 여부는 별도로 집계합니다.

## 커버·씰 사전 진단

커버 +Z 이동 시 씰과의 교차 부피는 0 mm에서 2664.3535 mm³, 0.1 mm에서 2437.7766 mm³, 1 mm에서 399.8889 mm³, 5 mm에서 0이었습니다. 반면 고정 초기 영역 밖 겹침은 0.1 mm에서 92.0159 mm³여서 기존 정책이 차단했습니다. 씰 +Z와 본체는 0 mm에서 50.6642 mm³, 0.5 mm에서 0이었습니다. 이 값들은 쌍별 위치 검사이며 전체 조립체 경로 통과 증명이 아닙니다.

근거: `runtime-data/native-validation/cover-seal-vertical-witnesses.json`, `cover-seal-vertical-after-cover.json`. 참고자료 원본은 읽기 전용이며 계산용 사본과 결과만 ver1 내부에 생성합니다.
