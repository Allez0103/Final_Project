# 자동 그룹화 완화 · 기준 부품 표시 · 시점별 공통 회전

2026-10-26. 배포 ZIP은 만들지 않고 개발 실행 파일만 갱신한다.

## 그룹화

`GroupingService.VERSION = grouping-v5-unique-unmatched-relaxation`.

기존 엄격 매칭 → 기존 0.1%/0.005mm 재시도 → 회전 매칭 → PLT용 조합 가지치기 순서는 유지한다. 그 뒤에도 남은 바디만 상대 체적·면적·AABB 치수 차이 **0.2%**, 중심 간 거리 차이 **0.01mm**로 마지막 재시도한다. 서로 다른 바디 집합이 정확히 하나임을 끝까지 확인하고 다른 정의와 후보가 경쟁하지 않을 때만 수락한다. 예산 초과·복수 후보·정의 경쟁은 미매칭을 유지한다. 이미 성공한 그룹의 ID, 이름, 종류, 구성은 변경하지 않는다.

추가 단계는 50,000노드·2초 탐색 예산 및 정의당 128바디 제한을 사용한다. 후보 메타데이터 구성까지 포함한 엄밀한 실시간 제한은 아니다. 기존 단계에서 입증한 복수/경쟁 결과를 더 넓은 기준으로 강제 수락하지 않는다. 진단 `GROUPING_RELAXED_MATCHES`와 `GroupingResult.relaxed_matches`에 실제 허용값과 완전 탐색 근거를 남긴다.

이는 그룹화 기준이며 접촉 거리, 초기 겹침, 이동 경로의 간섭 판정 허용값은 바꾸지 않는다. 새 분석에서 적용하고 기존 저장 프로젝트를 열기만 해도 그룹을 다시 만들지 않는다.

## 기준 부품

편집기 조립 순서 영역의 왼쪽에 `01 기준 부품 · 고정` 카드를 배치하고 나머지 카드 표시는 02부터 시작한다. 기준 카드는 이동/드래그할 수 없다. 클릭하면 영상 시작 시점으로 이동한다.

`Timeline.base_end`까지 기준 부품을 원래 위치에서 점멸 강조한다. 시간은 `max(0.5, highlight_sec)`초이고 이동 시간은 없다. 이후 기존 이동 단계와 부드러운 카메라 전환을 실행한다. 자재정보는 기준 부품 품명, 주의사항은 빈 값이다. 부분 초안의 미배치 부품을 숨기지 않는 기존 정책도 유지한다.

기준 부품은 `Plan.steps`에 넣지 않는 **표시 전용 첫 단계**다. 분해 탐색, 볼트 배치, 최초 초안, 확정 데이터의 학습 및 순서/방향 정확도 분모는 유지한다. 전체 제공파일의 이동 단계는 55개, 영상/목록 표시 단계는 기준을 포함해 56개다.

## 공통 회전

`Plan.camera_rolls`에 TOP/BOTTOM/FRONT/BACK/LEFT/RIGHT별 0/90/180/270도 값을 저장한다. 같은 시점을 쓰는 모든 단계에 적용하고 각 단계에서 시점을 선택하는 기능은 유지한다. AUTO의 실제 조립 방향이 6축 중 하나이면 그 시점과 공유한다. 탑뷰 자동 가로 정렬 값에는 사용자 공통 회전을 더한다.

회전 버튼 입력은 적용 전에는 임시 값이다. 미리보기는 계획 사본을 사용하고, 적용하면 해당 시점의 공통값과 기존 같은 시점 단계의 회전값을 함께 갱신한다. 실행 취소/다시 실행, 초안 저장, 확정, 재열기, 재생/탐색, MP4 출력에서 같은 값을 사용한다. 순서와 분해/조립 방향은 회전 때문에 바꾸지 않는다.

기존 단계별 회전은 공통값을 지정하지 않은 시점에서 호환용으로 유지한다. 해당 시점의 회전을 적용하면 공통값으로 통일된다. 앞으로 다른 단계에 그 시점을 선택해도 기존 공통값이 우선한다. 예전 프로젝트를 읽는 것만으로 원래 확정 JSON을 덮어쓰지 않는다.

## 저장 호환

기존 `plans`/`plan_steps` 컬럼 변경 없이 `plan_presentations` 테이블을 추가한다. plan_id를 기본키/외래키로, camera_rolls_json을 JSON으로 저장한다. 구형 DB는 `create_all()`로 새 빈 테이블만 추가한다. 확정 JSON과 생성 원본 JSON은 선택적 camera_rolls 필드를 포함한다. 필드가 없으면 빈 공통값으로 읽는다. 확인 서명은 공통값이 있을 때만 이를 포함한다.

실제 CAD와 격리 DB의 검증 결과는 작업 폴더 `experiments/PA2_PRESENTATION_20261026/RESULTS_KO.md`에 기록한다. 사용자 CAD/DB/로그/영상/학습 데이터를 소스 저장소에 자동 업로드하지 않는다.
