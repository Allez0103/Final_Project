# PLT 등 미매칭 다중 바디의 제한된 기준 바디 재시도

2026-10-26. 정책 `grouping-v4-bounded-unmatched-anchor-retry`.

기존 엄격·완화·회전 매칭이 모두 끝난 뒤 남은 바디 중, 단순 후보 조합이 50,000개를 초과하는 다중 바디 정의에만 추가 탐색을 한다. 기존에 성공한 그룹의 멤버·ID·종류·이름은 바꾸지 않는다.

- 후보가 적은 바디 우선, 동률이면 큰 체적 우선으로 배정한다.
- 같은 대상 바디 중복 배정과 상대 중심 거리 불일치를 즉시 제외한다.
- 엄격 기준에서 해답 없음이 확정된 경우 기존 미매칭 전용 기준(상대 0.1%, 위치 0.005mm)으로 재시도한다. 기존 간섭·접촉 허용오차는 변경하지 않는다.
- 서로 다른 바디 집합의 복수 해답, 다른 부품 정의와의 후보 경쟁, 불완전 탐색은 수락하지 않는다. 같은 바디 집합의 대칭 배정 순서만 다른 경우는 같은 그룹으로 센다.
- 주 탐색 전체 50,000개 노드·2초 예산, 정의당 128바디 제한을 둔다. 조건을 입증하지 못하면 미매칭을 유지한다.
- `GroupingResult.anchor_matches`와 가져오기 진단 `GROUPING_ANCHOR_MATCHES`에 근거를 기록한다.

제공 PLT는 9바디의 후보 조합 65,536개 때문에 기존 탐색이 중단됐다. 일부 중심 거리의 미세 차이가 엄격 기준도 넘으므로, 이미 있던 완화 기준에서 유일성을 확인했다. 새 결과는 자동 `PLT-KD000` 그룹 1개이며 미매칭 9→0, 전체 그룹 64→56이다. 제공파일의 다른 기존 55개 그룹과 더미 100종의 모든 그룹 구성은 같았다. 총 101개 조립체·11,484바디를 대조했고 집중 시험 33개, 전체 회귀 410개 통과·2개 건너뜀을 확인했다.

새 분석에 적용되며 기존 저장 프로젝트를 열기만 해도 그룹이나 확정 순서를 다시 쓰지 않는다. 원본 CAD·사용자 DB·간섭/순서/학습 코드는 유지했다. 이번 작업은 소스 수정과 인식 검증이며 배포 EXE/ZIP 및 GitHub 갱신은 포함하지 않는다. 전체 단계의 간섭·조립 가능성을 새로 검증한 결과는 아니다.

상세 근거는 개발 프로젝트의 `experiments/PLT_GROUPING_20261026/RESULTS_KO.md`와 `comparison.json`에 있다. 입력 CAD나 실제 실행 기록을 소스 저장소에 자동 포함하지 않는다.

후속 v29에서는 이 PLT 단계를 그대로 유지하고, 마지막 미매칭 전용 0.2%/0.01mm 단계를 추가한다. 기준 부품 표시·공통 시점 회전 및 실행 파일 적용은 `V29_GROUP_BASE_COMMON_VIEWS.md`와 후속 검증 기록을 참조한다. 위의 EXE 미갱신 문장은 앞선 PLT 단독 작업 시점의 기록이다.
