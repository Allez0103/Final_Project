# v11 후보 선정·중복 탐색 변경 실측 결과

## 결론

요청한 대상 부품 중심 후보 선정과 중복 재방문 억제를 구현했습니다. 실제 모델에서 **기존과 동일한 32개 부품의 검토용 초안**을 얻었으며 순서만 달라졌습니다. **이번 실측은 속도 개선에 성공하지 못했습니다.** 후보 기록은 줄었지만 1시간 제한에 도달해, 이전보다 12분 26초 오래 실행됐고 최종 잔여 상태의 진단도 완료하지 못했습니다.

## 동일 조건 비교

모델 65그룹, 이동 대상 64그룹, 동일 기준 부품, 접촉 121개, 지지 간선 56개. 전체 3,600초 / 후보 180초 / 개별 native 연산 120초 / 최대 방향 24 / 역추적 깊이 3·횟수 100으로 설정은 동일합니다. 형상 정책은 양쪽 모두 `path-v10-decreasing-overlap-review`이며 초기 겹침 감소·새 간섭 검사·지지 미검증 초안 기준을 변경하지 않았습니다.

후보 레코드는 **73.1% 감소**했지만, 중복을 제외한 고유 후보는 **0.82% 감소**에 그쳤습니다. 총시간은 **26.1% 증가**했습니다. 이전 기록 9,871개를 모두 새로운 고비용 CAD 계산으로 해석해서는 안 됩니다. 당시 2,674개 고유 키도 Boolean 연산 횟수는 아닙니다.

이번 2,652개는 신규 요청 783개와 차단 재사용 1,869개의 합입니다. 신규 경로 요청 대기 시간은 3,591.75초입니다. 정상 반환된 호출에서 부품 쌍 계산 1,123회, 부품 쌍 캐시 사용 60회, BREP_COMMON 활동 46,734회를 계측했습니다. 강제 종료된 호출 1개의 부분 작업 횟수는 이 카운터에 포함되지 않습니다. 한 방향 후보가 여러 상대 부품·여러 겹침 검사 위치·여러 면의 CAD 연산을 실행하므로 이 단위들은 서로 다릅니다.

## 무엇이 바뀌었나

- 먼 일반 부품 우선 → 대상 경로 검사 → 실제 차단 볼트·너트 우선, 나머지 접촉 체결 부품 다음 → 한 개 제거할 때마다 대상 재시도 → 실패 시 다른 대상 및 전체 후순위 후보.
- 한 체결 부품이 막혀도 다른 관련 체결 부품은 계속 시도합니다. 고립 체결 부품도 후순위에서 제외하지 않습니다.
- 동일 잔여 집합의 부품 판정 재사용, 동일 부품의 다른 통과 방향으로 같은 자식 상태 재방문 방지, 완전히 탐색한 상태 재방문 억제.
- 차단 상대가 남아 있고 방향·이동 거리가 같을 때만 다른 상태의 차단 근거를 재사용합니다. PASS/UNKNOWN 전체 경로를 다른 상태로 전용하지 않습니다.
- 재사용 결과의 이번 계산 시간은 0이며, 원래 계산 시간·출처 상태를 따로 보존합니다. GUI 진단과 진행 메시지에서 신규 요청과 차단 재사용을 분리합니다.

실측에서 관련 체결 부품 시도 92회, 제거 후 대상 최우선 재시도 30회, 같은 상태의 중복 부품 후보 건너뛰기 45회를 기록했습니다. 반면 이번 실행은 최초 제거 경로를 내려간 뒤 시간 제한에 도달했습니다. 상태 방문 33회/고유 상태 33개, 탐색 완료 상태 0개, 완료 상태 건너뛰기 0회, 부품 판정 재방문 캐시 0회입니다. 따라서 **실제 모델에서 완료 상태 가지치기 효과를 측정했다고 주장하지 않습니다.** 그 동작과 미완료 상태를 잘못 닫지 않는 조건은 합성 회귀 시험으로 검증했습니다.

구현·캐시 유효 조건은 [설계 설명](TARGET_FASTENER_SEARCH.md)에 정리했습니다.

## 시간 증가가 발생한 구간

아래는 고유 키별 기록 중 신규 계산만 합산한 경로 계산 시간입니다. 전체 실행 시간과는 계측 범위가 다릅니다. 이전 레코드의 중복과 이번 차단 근거 재사용은 제외했습니다.

| 부품 | 이전(초) | 변경(초) | 증가(초) |
|---|---:|---:|---:|
| source · 바디 42 | 117.0 | 365.4 | 248.4 |
| HVSC 2800 #2 | 138.4 | 337.4 | 199.0 |
| BLK-KD000 | 35.5 | 183.2 | 147.6 |
| COV-KD000 | 79.6 | 218.6 | 139.0 |
| source · 바디 41 | 89.0 | 190.2 | 101.3 |
| source · 바디 44 | 331.6 | 414.4 | 82.8 |

일반 부품을 먼저 선택하면서 체결 부품이 남아 있는 상태의 여러 방향을 정밀 검사하고, 제거 후 대상 경로를 다시 평가하는 비용이 늘었습니다. 이동 거리가 달라지면 동일 이동만 허용하는 차단 재사용 조건을 만족하지 못해 새 계산이 필요합니다. 기존에는 볼트가 먼저 제거된 상태에서 처음 검사하던 일반 부품도 새 구조에서는 더 이른 상태부터 검사합니다. 예를 들어 HVSC #2의 신규 요청은 이전 고유 키 18개에서 이번 54회로 늘었습니다.

개별 고비용 연산 자체의 속도는 개선하지 않았습니다. BLT-WASM620R #11의 통과 계산은 이전 148.83초, 이번 약 149.1초입니다. **요청 수 감소와 CAD 연산 시간 감소는 같은 것이 아닙니다.** 단일 실제 실행끼리의 비교이며 다른 모델에서의 성능을 보장하지 않습니다.

## 순서와 잔여 진단 범위

이전 제거 부품 집합과 이번 제거 부품 집합은 완전히 같습니다(추가 0개, 누락 0개). 커버는 19번째, 씰은 29번째 제거 단계입니다. 조립 순서는 이 제거열의 역순입니다. 30단계에 초기 겹침 감소 예외, 32단계에 지지 미검증 경고가 유지됩니다. 새 간섭이나 미판정을 통과시켜 단계 수를 맞춘 것이 아닙니다.

최종 잔여 집합의 해시는 이전과 같지만 이번 실행에서는 바디 44의 16방향(차단 14 / 미판정 2)만 기록하고 시간 제한에 도달했습니다. 마지막 미판정은 BREP_COMMON 계산 중 전체 예산 종료입니다. **다른 잔여 31개는 이 최종 상태에서 아직 검사하지 않았으므로 이번 실행만으로 전부 차단이라고 판정하지 않습니다.** 이전 v10의 잔여 23개 차단·9개 미판정 분류는 과거 실행의 진단입니다. [이번 잔여 상태의 검사 범위](REMAINING_PARTS_TARGET_V11.md), [이전 상세 진단](REMAINING_PARTS_DECREASE_V10.md)을 구분해 확인하세요.

전체 순서는 미완성이고, 32단계가 가능한 최대치라는 증명도 아닙니다. 기존 사용자 초안·확정 계획은 덮어쓰지 않았습니다.
