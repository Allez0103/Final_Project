# 영상 시작 카메라: 첫 조립 단계 기준 가로 정렬

2026-10-26. v29의 기준 부품 표시 및 시점별 공통 회전은 유지한다.

1. 기준 부품 다음 실제 첫 이동/조립 단계(`Plan.steps[0]`)의 시점을 읽는다. 카드 순서를 바꾸면 새 첫 단계가 기준이 된다.
2. 단계의 카메라 선택, 기존 탑뷰 가로 정렬 및 시점별 사용자 회전값을 먼저 반영한다.
3. 완성 모델의 고정 AABB를 해당 카메라의 화면 가로/세로 축에 투영한다. 세로가 더 길면 화면을 추가로 90도 회전한다. 동일/거의 같은 크기이면 회전하지 않는다.
4. 그 시점의 다른 단계에도 같은 추가 보정을 적용한다. AUTO는 실제 6축 시점과 공유하고, 비축 AUTO는 같은 방향끼리만 보정한다.
5. 기준 부품 표시 시작 카메라를 보정된 첫 조립 카메라와 정확히 동일하게 사용한다. 첫 단계의 카메라 전환 시간은 0이다. 이후 다른 시점으로 넘어가는 기존 부드러운 회전은 유지한다.

`Timeline.start_camera`, `step_cameras`, `first_view_landscape_roll_deg`에 계산 결과를 저장하고 미리보기/재생/탐색/영상 출력이 같은 결과를 소비한다. 보정은 표시 계산으로만 수행하며 계획의 시점별 공통 회전 저장값, 분해·조립 방향, 순서, 확정 데이터는 덮어쓰지 않는다. 첫 시점이 세로가 되는 회전값을 저장했더라도 이번 요구사항대로 가로 정렬이 우선하여 추가 90도 보정이 생길 수 있다. 다른 시점은 영향을 받지 않는다.

완성 모델의 AABB만 사용하므로 BREP·접촉·간섭 재계산은 없다. 움직이는 부품을 따라 화면 맞춤/줌/카메라 중심을 재계산하지 않는다. 첫 단계가 없는 기준 부품 단독 계획에서는 종전의 탑뷰 가로 정렬 시작을 유지한다.

이전 v29 문서와 시험 영상의 탑뷰 고정 시작은 당시 동작 기록이며 이번 버전에서는 위 정책으로 대체한다. 상세 시험 결과는 `experiments/PA2_FIRST_STEP_CAMERA_20261026/RESULTS_KO.md`에 기록한다. 배포 ZIP은 생성하지 않는다.
