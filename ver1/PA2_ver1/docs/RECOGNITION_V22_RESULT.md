# v22 인식 확인 결과

작업일: 2026-10-22

## 결과

파일명 분류를 확장하고 S08의 회전 매칭을 보완했다. 새 EXE에도 반영했다. 확인 범위는 STEP 읽기·부품 종류 분류·개별 부품 형상 대응뿐이다. 접촉 그래프/간섭/순서/학습/모델 평가/영상은 실행하지 않았다.

- 모든 샘플의 볼트 수가 동봉 assembly_manifest의 수량과 일치했다.
- 매칭 모호성 0건. 수정 전에 이미 대응된 그룹의 ID·멤버·품명·부품 정의 대응은 모두 보존했다.
- S08은 회전 불변 특징으로 23개, 형상 특징과 STEP 내부 부품 참조명을 함께 대조해 좌·우 버스바 4개를 추가 대응했다.
- 테스트한 모든 더미 완제품 바디는 현재 importer의 기본 유효성 검사에서 유효했다. 이는 경로·중간 조립 상태·기능 안전성 검증을 뜻하지 않는다.
- 종류가 UNKNOWN인 일반 부품은 총 246개 남는다. 퓨즈·PCB·저항·센서·지지구/단자 등 기존 PartType에 정확한 종류가 없는 부품이며 **미매칭/누락이 아니다**. 부품명과 형상 대응은 유지한다. 볼트를 일반 부품으로 잘못 넣던 기존 문제와 구분한다.
- 구매 모듈 단위 묶기나 동봉 예시 순서의 자동 입력은 이번 범위에 없다. S02의 131바디를 동봉 예시의 115작업으로 자동 변환한 결과가 아니다.

## 기존 제공파일 회귀 확인

바탕화면 `제공 파일/제공 파일/3D DATA/STP`의 완제품과 개별 부품 18개를 새로 읽어 수정 전후를 비교했다.

- 완제품 176바디, 원시 자동 매칭 결과 64그룹: 전후 동일.
- 그룹 전체 필드(ID·멤버·이름·부품 종류·체적·중심·상자 등): **수정 전후 완전히 동일**.
- 체결부는 볼트 37개 + 너트 4개 = 41개로 동일.
- 원시 자동 매칭에서 기존에 남던 익명 바디 9개는 그대로 9개다. 이번 수정으로 새 미매칭이 생기거나 기존 그룹이 바뀌지 않았다. 이 비교는 사용자가 수동 그룹화한 저장 프로젝트가 아닌, 원시 STEP 자동 대응 기준이다.
- 기존 AIR-BENT 재시도 정책을 유지했다. 상대 0.1%/위치 0.005mm 재시도와 새 회전 재시도는 별개다.
- 원본 재읽기에서 STEP 파서의 기존 `BSpline curve: # Poles and degree mismatch` 경고가 변경 전후 동일하게 기록됐다. importer는 176개 유효 솔리드를 읽었으며 기존 그룹 결과도 동일했다. 이번에는 원본 곡선 수리나 간섭 기준 변경을 수행하지 않았다.

## 변경 금지·원본 보존 확인

- 간섭/접촉/경로/Boolean·설정 및 순서·학습 관련 보호 소스 15개 해시: **전후 일치**.
- AppSettings 전체 필드: **전후 일치**. 간섭 epsilon, 접촉 간격, 초기 겹침 허용 기준 모두 변경 없음.
- 더미 STEP 346개(완제품 10개 + 유형 STEP 336개), 기존 제공 STEP 19개: **전후 365개 해시 일치**.
- 바탕화면 원본·사용자 DB·기존 프로젝트/영상·배포 ZIP은 수정하지 않았다.
- 동봉 스크립트를 실행하지 않았다. JSON은 확인용 볼트 수량 비교에만 사용했고 실제 형상 대응은 CAD와 STEP 내부 메타데이터로 수행했다.
- 학습과 모델 검증은 실행하지 않았으며 자동 학습/자동 적용 기본 OFF도 그대로다.

## 수행한 시험·빌드

- 기존/추가 이름 규칙, 기존 그룹화, 회전 불변 특징, 반복 배치, 여러 정의 경쟁, 다중 바디의 강체 상대 거리, 특징 실패 시 미매칭 유지, STEP 이름의 제한된 tie-break: **62 passed / 1.30초**.
- 구문 검사 통과.
- PyInstaller 빌드 성공.
- 최종 EXE의 최적화 코드와 소스 **52개 모듈 전부 일치**, 아이콘/로고/영상 템플릿 일치.
- 이번에는 GUI 전체 워크플로/자동 순서/영상/학습 시험을 재실행하지 않았다.
- 더미 10종의 읽기·종류 분류·형상 대응 합계는 약 29.99초였다. 기존 복잡 STEP 재읽기는 약 214.78초였다. 서로 다른 데이터·실행 환경의 전체 순서 생성 시간으로 해석하면 안 된다.

- 실행 파일: `ver1/PA2_ver1/PA2.exe`
- 크기: 23,635,038 bytes
- SHA-256: `cc0c0a303d786c11516d592966502983db8820ecaee1fb9471d714c87ddd8bb8`
- 이전 EXE·의존 파일: `build/previous-release-v22-import-20261022/`에 이동 보관, 삭제하지 않음.
