# v20 보완사항 구현 및 검증 범위

## 사용자 작업 흐름

- STEP 대표 색상 하나를 부품에 적용한다. 전체 부품 색상 우선, 면 색상만 있으면 면적 합이 가장 큰 색상. 그룹은 바디별 대표 색상의 면적 합으로 대표색 하나를 정한다. 색상이 없거나 매칭이 모호하면 기존 자동 색상을 사용한다.
- 단일 선택은 불투명 빨강, 나머지는 회색/불투명도 25%. 다중 부품 선택은 기존 선택 부품 단독 표시. 선택 해제 시 이전 속성과 표시 상태 복원.
- 영상과 단계 미리보기: 빨간 점멸 → 이동 중 빨강 유지 → 대표색 복원. 주변 부품은 영상에서 반투명화하지 않는다.
- 자동생성 옆에 수동생성. 일반 부품은 현재 부품 목록의 조립 순서, 분해 +Z(조립 −Z) 초기값으로 즉시 배치한다. 사용자가 기존 편집기로 변경할 수 있다.
- 수동생성은 일반 부품 경로·간섭·지지·노출도·백트래킹 검사를 하지 않는다. 기존 접촉 관계만 재사용하며, 접촉 그래프 업그레이드도 이 버튼에서 실행하지 않는다. 오래된 불완전 접촉 자료는 체결부 배치의 정확도를 보장하지 못하므로 새 모델 분석 결과를 권장한다.
- 볼트/너트는 축·머리 방향을 기존 방식으로 계산한다. 공유 체결부는 마지막 관련 일반 부품 뒤, 기준 부품 연결/연결 대상 없는 체결부는 일반 부품보다 앞에 배치한다. 그룹 내부 체결부를 중복 삽입하지 않는다.
- 수동생성에서는 예외 부품도 일반 부품 목록 순서를 유지하며 예외 태그를 보존한다. 자동생성의 기존 예외 우선 제거 정책과 구분된다.
- 초안 저장 버튼 제거. 생성 원본은 별도 불변 레코드로 자동 보존. 적용한 편집/순서 이동/실행 취소는 편집 초안에 자동 저장. 입력만 하고 적용하지 않은 속성은 저장·확정된 값으로 간주하지 않는다.
- 순서 확정은 필수. 확정 후 변경하면 재확정 전 영상 생성 차단. 편집/확정/영상에서 CAD 재검사 없음.

## 데이터와 학습

- 신규 테이블: plan_generations(생성 원본·기존 검사 근거·성능), confirmation_analyses(초안–확정 비교), learning_observations(확정 선호·방향·예외·주변 상태).
- 기존 DB는 create_all로 새 테이블만 추가한다. 기존 테이블/확정/프로젝트 원본은 덮어쓰지 않는다. Alembic baseline 및 추가 테이블 revision도 제공한다.
- 구버전 최초 planning JSON이 남아 있으면 생성 원본을 복원한다. 편집된 DB 초안을 원본으로 대체하지 않는다. JSON이 없으면 원본 비교 불가로 표시한다.
- 전체/일반 부품/일반 중 예외 제외의 선후 관계 유지율, LCS, 방향 일치율(1도 허용)을 저장한다. 한 개 이하의 비교 대상은 해당 비율을 NULL로 표시한다.
- 예외 부품 포함 전체 확정 데이터를 보존한다. 순서 학습 후보는 일반 부품만 사용한다. 예외가 있다는 이유로 사례 전체를 버리지 않는다.
- 사용자 선호, 원래 검사 상태, 검사 당시 remaining state/direction/travel/policy를 구분한다. 예외·UNKNOWN·NOT_TESTED에 physical PASS/FAIL 라벨을 만들지 않는다. 사용자 방향 수정으로 기존 방향에 실패 라벨을 만들지 않는다.
- 반복 확정은 관찰 서명으로 중복 제외하고, 같은 순서는 ranking case 중복 제외. 텍스트/카메라 수정은 새 순서 사례가 아니다. 계열 중복 억제 키는 바디 체적·경계 크기·바디 중심 간 거리의 0.001 단위 반올림 조합이다. 파일명·STEP 메타데이터·사용자 그룹화는 키에 넣지 않는다. 이는 근접 제품 변형의 완전한 자동 분류가 아니므로 실제 독립 계열 평가에서는 이를 추가 검토해야 한다.
- 상단 학습 현황에서 계열·일반 부품 선택 상태·관찰 기록과 현재 확정본 유사도를 확인한다.
- 오프라인 순서 학습 CLI: `PA2.exe --cli learning-status --data-root ...`, `PA2.exe --cli train-ranking --data-root ... --output <새 폴더>`.
- 기본 학습 기준은 계열 30개 AND 순서 선택 상태 1,000개. --pilot은 계열 10개 이상의 명시적인 예비 실험. 후보 행 수는 선택 사례 수가 아니다.
- 가족 단위 학습/평가 분리, CPU 1스레드. 실험 모델과 평가를 저장하되 자동 활성화하지 않는다. 기본 자동생성은 기존 규칙을 유지한다. 실제 CAD 호출·시간·생성 단계 비교 전에는 추천 모델로 승격하지 않는다.
- 방향/예외 추천용 관찰 데이터까지 수집하되, 데이터 부족 상태에서 가짜 모델을 생성하지 않는다. 방향·예외 모델의 일반화 학습/적용은 이후 충분한 유형별 실데이터와 평가를 확보한 뒤 진행한다.
