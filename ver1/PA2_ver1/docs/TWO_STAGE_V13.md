# v13: 체결물 없는 초안과 실제 순서 재구성

일반 부품의 가상 분해에서는 기준 부품을 제외한 모든 BOLT/NUT를 임시 제외한다. 외부 노출도가 높은 일반 부품부터 6축 경로를 검사하고, 첫 통과 방향을 채택해 일반 부품 초안을 만든다. 일반 부품끼리의 차단·미판정은 그대로 유지한다. 이 초안은 실제 제거 성공이나 지지 검증으로 취급하지 않는다.

실제 조립 상태에서 초안 우선순위를 따라 경로를 다시 검사한다. 볼트·너트가 막으면 관련 체결물 묶음을 실제로 제거한 뒤 목표 일반 부품을 재검사한다. 볼트 하나마다 목표 부품의 6방향을 반복 검사하지 않는다. 묶음 중 일부가 다른 일반 부품에 막히면 다른 일반 부품을 먼저 시도하며 원래 초안을 변경할 수 있다. 묶음을 모두 제거하지 못해도 후순위에서 목표 부품의 현재 경로를 확인하므로 단순 접촉을 필수 체결로 단정하지 않는다. 접촉 체결물과 고립 체결물도 후보에 남긴다. 모든 단계는 첫 허용 방향을 찾으면 다른 방향 검사를 중단한다. 잔여 집합 단위 완료 상태와 평가 결과 재사용으로 중복 탐색을 줄인다. 완전히 탐색하지 않은 상태를 완료 상태로 저장하지 않는다.

일반 부품 방향은 ±X, ±Y, ±Z만 사용한다. 현재 접촉 상대와의 초기 체적 겹침이 있으면 기존 AABB 투영 노출도를 사용한다. 겹침이 없고 평면 접촉 패치를 구할 수 있으면 가장 넓은 패치에서 멀어지는 법선을 6축에 투영해 우선순위를 정한다. 곡면·불명확한 접촉·힌트 계산 실패는 노출도로 대체한다. 힌트는 통과 근거가 아니다. 접촉 패치와 초기 겹침 힌트 계산 시간·호출 수는 경로 검사와 별도로 계측한다.

볼트·너트는 가장 넓은 원통면의 축 양방향을 우선하며 양쪽 중 노출도가 높은 방향부터 검사한다. 양쪽이 실패하면 나머지 6축 후보를 검사한다. 축과 겹치는 후보는 중복 제거한다. 원통 축을 찾지 못하면 6축 노출도 순으로 검사한다. 나사 풀림 회전이나 공구 접근성은 검증하지 않는다.

사용자 지정 예외는 분해 선두에서, 6축 노출도 1순위 방향으로 경로·지지 검사 없이 제거 처리한다. 경로 판정은 `NOT_TESTED`, 단계 표시는 `USER_COLLISION_EXCEPTION`으로 기록한다. 기준 부품은 예외로 지정할 수 없다. 이후 자동 검사에서는 이미 제거된 예외 부품을 장애물·지지 접촉에서 제외한다. 조립 계획은 분해 역순이므로 해당 단계가 마지막에 나타난다. 사용자는 방향·거리·순서를 수정한 후 확정할 수 있으며, 편집·저장·재열기·확정 후에도 예외 표시를 보존한다.

기준 부품과 예외 선택은 프로젝트/입력 스냅샷에 맞춰 저장한다. 새 입력 스냅샷에는 이전 선택을 자동 적용하지 않는다. 원본 CAD에는 쓰지 않는다. 이번 실제 모델 실행의 예외 부품은 `LV CONT` 하나다.

초기 겹침 감소 허용, 새 간섭 검사, 미판정 처리, 지지 미검증 초안 허용은 기존 정책을 유지한다. 생성된 일반 부품 초안과 실제 순서, 사용자 예외를 각각 기록한다. 결과·성능 수치는 실제 실행 완료 후 별도 결과 보고서에 기록한다.
