# v12 외부 노출·체결부 가상 제거 탐색

사용자 요청에 따라 고정 부품 중심에서의 거리를 후보 우선순위에서 제외했다. 현재 잔여 부품의 경계 상자를 각 방향의 직교 평면으로 투영하여, 전방의 투영 중첩 면적 비율과 상대 수를 계산한다. 전역 6방향 중 가장 적게 가려진 일반부품을 우선한다. 동률이면 위쪽 노출, 총 가림 정도, ID 순서다. 기준 부품은 제거 후보에서만 제외하고 가림 평가와 실제 충돌 검사에는 유지한다. 부품이 제거될 때마다 다시 계산한다. 경계 상자는 순위용 근사이며 통과/차단의 증거로 사용하지 않는다.

대상 일반부품은 가림이 적은 실제 형상 방향 중 상위 2개를 먼저 검사한다. 바로 통과하지 않으면 접촉 그래프의 볼트·너트와 경로에서 확인된 차단 체결부를 모두 가상으로 제외하고 상위 2방향을 검사한다. 접촉은 체결 연결의 대리 지표이며 실제 나사 연결 의미를 확인한 것은 아니다. 가상 검사는 지지 조건을 증명하지 않으며 실제 순서에는 들어가지 않는다.

가상 검사에서 통과한 경우 현재 실제 상태로 돌아와 관련 체결부를 하나씩 정밀 검사한다. 통과한 부품만 제거하고 남은 체결부를 계속 검사한다. 한 부품이 막혀도 다른 관련 체결부를 시도한다. 모두 제거되면 대상 일반부품을 가상 검사 성공 방향부터 실제 상태에서 다시 확인한다. 실제 제거 중 지지 미확인은 기존 검토용 초안 정책을 따른다.

가상 검사 실패·미판정이면 다음 일반부품을 먼저 시도한다. 일반부품의 빠른 선검사가 끝나면 후순위에서 볼트·너트를 먼저 검사하고 일반부품의 나머지 방향을 확장한다. 모든 잔여 부품과 모든 생성 방향을 유지하므로 초기 2방향 또는 접촉 관계만으로 영구 제외하지 않는다. 전역 예산, 후보 제한, 생성된 유한 직선 방향의 한계는 그대로 기록한다. 실패는 물리적 분해 불가능의 증명이 아니다.

가상 검사와 실제 경로의 캐시/진단은 분리한다. `planning.paths`는 실제 상태, `planning.metrics.virtual_paths`는 가상 상태다. 실제 `tested_candidates`와 가상 `virtual_candidate_records`를 구분한다. `native_path_calls`는 양쪽의 신규 요청 합이며 `actual_native_path_calls`, `virtual_native_path_calls`로 나눈다. 차단 증거는 실제 상태에서 얻은 것만 등록하고, 동일 이동과 해당 차단 상대의 잔존 조건을 확인한다. 가상 PASS를 실제 제거 단계로 복사하지 않는다. 워커 내부의 부품 쌍 캐시는 같은 형상·정책·이동 조건일 때만 재사용한다.

부분 영상은 사용자가 승인한 이번 요청에 맞춰 별도 지원한다. 일반 계획 검사는 전체 그룹 일치 조건을 유지하며, 영상/부분 확정 경로에서만 부분 상태의 유효한 부분집합을 허용한다. 중복·외부 그룹·기준 부품의 이동 단계는 허용하지 않는다. 부분 확정은 학습 정답으로 수집하지 않는다. 영상은 전체 미계획 그룹을 정지 상태로 유지하고 하단에 부분 단계 수를 표시한다. 긴 자동 경고는 영상에서 핵심을 읽기 쉽게 표시하고 원문은 계획 JSON에 보존한다.

`tools/validate_native_pipeline.py --assembly ... --parts ...`는 새 작업 데이터 루트에 외부 원본의 관리 사본을 만들고 새 캐시로 입력→대응→접촉→순서 생성을 실행한다. `tools/render_recorded_plan.py`는 해당 결과의 저장→미리보기→부분/전체 확정→재열기→1080p30 MP4→해시 확인 내보내기→전체 디코딩을 검증한다. `tools/audit_retained_state.py`는 확보한 최장 제거열 끝 상태에서 별도 제한 방향 진단을 수행하며, 추가 단계를 자동으로 확정하지 않는다.
