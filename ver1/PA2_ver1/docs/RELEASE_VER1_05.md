# PA² ver1_05 사내 배포 변경 내용

2026-10-26. Windows x64, Python 별도 설치 없이 ZIP 전체 압축 해제 후 `PA2_ver1/PA2.exe`를 실행한다. `_internal`을 EXE와 함께 유지한다. 제거 프로그램은 `uninst.exe`다.

## ver1_04 이후 반영

1. **PLT 자동 그룹화**: 반복되는 다중 바디의 단순 조합 상한 때문에 실패하던 경우를 기준 바디/중심 거리 가지치기로 재시도한다. 제공 PLT 9개 바디가 하나의 자동 그룹으로 묶인다.
2. **미매칭 전용 기준 완화**: 기존 성공 그룹은 보존하고, 모든 기존 단계 뒤에만 상대 체적·면적·AABB 치수 0.2%, 중심 간 거리 0.01mm로 재시도한다. 유일 후보/비경쟁/완전 탐색인 경우만 수락한다. 간섭 기준은 변경하지 않는다.
3. **기준 부품 표시**: 조립 순서의 01 고정 카드와 영상 첫 단계에 표시한다. 위치는 고정하고 강조만 적용한다. 분해 탐색/학습용 이동 단계에 추가하지 않는다.
4. **시점별 공통 화면 회전**: 정면/후면/좌측/우측/상단/하단별 회전값을 같은 시점을 쓰는 모든 단계에 공유한다. AUTO는 실제 같은 축 시점과 공유한다. 저장·확정·재열기·실행 취소·미리보기·영상에 반영한다.
5. **첫 조립 단계 기준 영상 시작**: 첫 실제 조립 단계의 카메라로 기준 부품 표시를 시작하고 모델을 가로로 보정한다. 첫 단계로 넘어갈 때 불필요한 회전이 없다. 같은 시점의 후속 단계에도 같은 보정을 사용한다. 저장된 회전값은 덮어쓰지 않지만 첫 시점 가로 표시를 위해 추가 90도 보정이 생길 수 있다.
6. **기준 카드 선택 후 다른 카드 전환 수정**: 영상 표시에서 숨기거나 이동시킨 부품을 편집 상태로 복원하고, 같은 카드를 다시 눌러도 작업 속성을 다시 연결한다. 기존 다중선택/숨김 정책은 유지한다.

기존 자동·수동생성, 순서/방향 편집·확정, 영상 생성, 승인된 순서·방향 모델, 확정 프로젝트 10개 단위 재학습 정책, 로그/외부 공유용 accuracy_log, 제거 기능을 유지한다. 이번 버전에서 새 재학습이나 자동 예외 축소 실험을 적용하지 않았다.

## 검증 요약

- 그룹화: 제공파일+더미 101개 모델, 11,484개 바디 비교에서 기존 그룹 구성 보존. 제공파일 56개 그룹, 미매칭 0개.
- 제공파일 초안: 기존 예외 5개를 유지한 시험에서 이동 55단계+기준 1단계 표시, 후보 9개, 생성 약 117.8초. 검토용 초안이며 전 단계 무간섭 검증 완료를 뜻하지 않는다.
- 실제 제공 CAD 전체 편집 영상 3,015프레임과 첫 PLT 조립 1080p 샘플 201프레임 전체 읽기 확인. 시작부터 첫 조립까지 카메라 각도·중심·줌 변화 없음.
- 기준 카드 문제는 수정 전 실제 마우스 재현 5개 실패, 수정 후 기본/추가 회귀 9개 통과. 최종 전체 472개 중 470개 통과, 2개 건너뜀.
- 실제 EXE에서 프로젝트 재열기 및 기준 카드→일반 카드 재선택/속성 갱신 확인.

측정 시간은 해당 개발 PC와 시험 조건의 결과이며 다른 PC에서 같은 속도를 보장하지 않는다. 이 배포는 같은 PC에서 독립 압축 해제 실행을 확인하는 사내 전달용이며 별도 수신 PC 시험은 필요하다.

## 알려진 제한과 주의

- **과거 색상 누락 캐시**: STEP 대표 색상 읽기는 구현되어 있지만, 색상이 저장되지 않은 이전 캐시를 사용하면 대체 색상이 나온다. 이 캐시 문제는 이번에 수정하지 않았다. 새로 읽은 제공 STEP에서는 176개 바디의 색상이 모두 인식됐다. 빨간 강조는 의도한 표시다.
- **한글 설치 경로의 초기 모델 오류**: LightGBM 모델 파일 열기 실패가 보고됐으며 해결 완료로 표시하지 않는다. 문제가 생기면 폴더 전체를 영문 경로(예: `D:\PA2_ver1`)에 둔다. 기존 규칙으로 복귀하더라도 학습 모델 적용 성공을 뜻하지 않는다.
- 자동 초안은 담당자 검토·편집·확정 대상이다. 지정 예외, 볼트/너트 경로 검사 생략, 지지 미검증 초안 정책을 유지한다. 확정 순서 유사도는 실제 간섭 정확도가 아니다.
- 사용자 순서/방향 편집 및 영상 재생성은 간섭 재검사 없이 진행한다. 기존 MP4는 자동 변경되지 않는다.
- ZIP에는 개발자의 실제 사용자 CAD/프로젝트 DB/실행 로그/영상이 없으나, 기존 승인된 초기 모델과 해당 학습 참고 번들은 포함된다. 소스 전용 Git 저장소에는 이 번들을 포함하지 않는다.
- 프로그램을 지우기 전 필요한 프로젝트를 백업한다. `uninst.exe`는 등록된 관리 영역을 대상으로 하며 외부 원본 STEP을 삭제하지 않는다.
- EXE는 전자서명되지 않았다. 포함된 라이브러리 고지는 외부 공개 배포용 라이선스 검토 완료를 의미하지 않는다.
