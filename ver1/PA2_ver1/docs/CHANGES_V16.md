# v16 적용 내용

사용자가 합의한 후속 요구를 적용한다. 원래 구현 명세의 초기 기본값보다 이번 정책을 우선한다.

- 체결부 연결 관계를 보존하고, 볼트·너트를 제외한 일반 부품의 제거열을 한 번만 탐색한다. 동일 잔여 상태 캐시·장애물 차단 근거 재사용·통과 방향에서 조기 종료를 유지한다.
- 일반 부품은 외부 노출도 순위로 검사한다. 방향은 6축이며 큰 접촉면의 법선 방향을 우선하고 초기 겹침 등으로 접촉 법선을 확정할 수 없으면 노출도를 사용한다.
- 일반 부품 초안 완성 뒤 관련 체결부를 분해 직전에 삽입한다. 볼트–너트 연결 경로로 공유 체결 대상을 수집하며, 여러 연결 부품 중 가장 먼저 분해되는 부품 앞에 한 번만 삽입한다. 고정 부품 전용 또는 접촉 대상 미확인 체결부는 말미에 배치하고 내부 근거를 남긴다.
- 볼트·너트는 축방향으로 체결 대상과 멀어지게 배치한다. 상세 경로 검사는 수행하지 않으며 일반 UI에 미검증 경고를 붙이지 않는다. 내부 NOT_TESTED 기록은 유지한다.
- 사용자 예외 부품은 LV CONT와 HVSC 2800 #1/#2다. 예외 연결 체결부가 먼저 분해되고 예외 부품이 이어진다. 예외 부품은 간섭·지지 검사 없이 노출도 첫 방향을 사용한다.
- 후보 제한 기본값은 240초다. 기존 기본값 180초 설정은 v16에서 240초로 이행한다. 초기 겹침 감소·새 간섭 판정·릴레이 형상 보정·BSpline 분할 정책은 유지한다.
- 미해결 일반 부품도 전체 편집용 초안에 포함하며 실패 원인·미판정 근거는 보존한다. 편집용 전체 초안과 경로 검증 완료를 구분한다.
- 가로 형상 카드, 체크박스/Ctrl/Shift 다중선택, 묶음 드래그 및 앞뒤/번호 이동, 실행 취소/다시 실행/저장을 제공한다. 여러 항목의 작업 속성을 실수로 덮어쓰지 않도록 속성 편집은 단일 선택에서 수행한다.
- 작업 속성 영역에서 기준 1개 및 예외 여러 개를 지정한다. 3D 표준 시점·회전/이동/줌·화면 맞춤·모델 선택·하이라이트·숨김/단독/전체 표시를 연결한다.
- 수동 순서/방향 변경, 미리보기 갱신, 확정, 영상 재생성은 CAD 간섭 재검사를 호출하지 않는다. 형식 검사만 수행한다.
- 영상은 불변 확정 스냅샷을 렌더링한다. '재검토'는 현재 편집본을 새 확정본으로 저장한 뒤 검사 없이 새 영상을 생성한다. 기존 영상은 덮어쓰지 않는다.
- 프레임 기반 진행률, MP4 미리보기, 재생/일시정지/구간 이동, 0.5/1/1.5/2배속, 전체화면 및 Esc 해제를 제공한다. Qt Multimedia 구성요소를 배포 의존성에 추가한다.
- 고정 부품 기준 카메라와 일정 줌, 이동 전 하이라이트 점멸 및 이동 중 유지, 품명 기본 자재정보, 사용자 입력 주의사항, 빈 내용에도 템플릿 출력은 유지한다.

실제 수치와 잔여 원인은 END_TO_END_V16_RESULT.md 및 runtime-data/native-validation의 v16 JSON에 기록한다. 제공 자료와 기존 PILOT Studio는 읽기 전용으로 보존한다.
