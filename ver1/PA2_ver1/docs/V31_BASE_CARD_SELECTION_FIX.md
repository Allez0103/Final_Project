# 기준 부품 선택 뒤 일반 조립 카드가 표시되지 않는 문제 수정

2026-10-26.

문제는 실제 Qt 마우스 클릭으로 재현했다. 기준 부품 카드는 영상 시작 장면을 표시하기 위해 나머지 부품을 숨긴다. 이후 일반 카드의 기존 선택 처리에서는 색상만 강조하고 영상 장면의 숨김/이동 상태를 편집 모델로 복구하지 않아 선택 부품이 계속 보이지 않았다. 또한 `QListWidget.clearSelection()`은 current item을 유지하므로, 같은 카드를 다시 누르면 `currentItemChanged`가 발생하지 않아 작업 속성도 갱신되지 않는 경우가 있었다.

수정:

- 재생/탐색 화면에 들어가기 전에 편집 모델의 원래 표시 상태와 위치를 저장한다.
- 일반 조립 카드나 부품 목록을 선택하거나 표시 편집 동작을 실행하면 원래 편집 상태를 복원한다. 이 복원은 카메라를 다시 맞추거나 줌을 변경하지 않는다.
- 영상이 숨긴 부품은 다시 보이게 하되, 사용자가 직접 숨겼던 부품은 숨김 상태를 유지한다.
- 단일 카드 선택 때 current item 변경 신호에만 의존하지 않고 선택한 단계의 작업 속성을 명시적으로 다시 연결한다.
- 같은 카드 재선택, 다중선택, 재생/스크러빙/다음 단계에서 편집 복귀, 속성 미리보기를 함께 검증한다.
- 기준 카드를 클릭하면 영상 시작을 표시하고, 일반 카드를 클릭하면 기존과 같이 전체 편집 모델에서 선택 부품을 강조한다. 일반 카드 클릭을 새 타임라인 이동 기능으로 바꾸지는 않았다.
- 선택/복귀는 순서, 방향, 확정 데이터, 간섭 판정, 영상 렌더링 알고리즘을 변경하지 않고 CAD 검사를 실행하지 않는다.

전후 재현 및 실행 파일 마우스 클릭 검증은 `experiments/PA2_BASE_CARD_FIX_20261026/RESULTS_KO.md`에 기록한다. STEP 색상 캐시 이슈는 별도 보류 사항이며 이번 수정에 포함하지 않는다. 배포 ZIP은 만들지 않는다.
