# 구현 및 검수 상태

기준: `PA2_Codex_최종_구현명세.md` 1.0. `통과`는 자동/실측 근거가 있는 항목, `부분`은 계약은 있으나 대표 모델 또는 배포 검증이 남은 항목, `미완료`는 핵심 작업이 남은 항목입니다.

2026-10-19 v16: 체결부를 제외한 일반 부품을 한 번 탐색한 뒤 체결부를 삽입하는 방식, 후보 240초, LV CONT 및 HVSC 2800 #1/#2 예외를 적용했다. 새 입력 19파일/65그룹에서 64/64단계 초안을 1,142.08초에 생성했다. 신규 CAD 요청 192회, 후보 기록 896개(차단 근거 재사용 704개), 일반 부품 경로 통과 17개·체결부 41개·예외 3개·미해결 3개다. 기준/예외를 작업 속성으로 옮기고 형상 가로 카드·다중 이동·실행 취소·3D 조작을 연결했다. 1080p30 기본 영상은 252.32초에 생성하여 8,355프레임 전체 디코딩을 통과했다. 배포 EXE의 실제 재검토 버튼으로 순서 및 +Z→-Z 방향을 변경한 64단계 영상은 238.62초에 생성했으며 CAD 재검사 0회, 8,400프레임 전체 디코딩, 진행률, 미리보기·구간 이동·2배속·전체화면·Esc 해제를 확인했다. [v16 정책](CHANGES_V16.md), [v16 실행 결과](END_TO_END_V16_RESULT.md). v14 이하 내용은 이전 검증 이력이다.

2026-10-19 v14: 사용자 후속 요구로 볼트·너트 축방향 배치, 미해결 일반 부품을 포함한 전체 편집용 초안, 고정 부품 기준 카메라, 하이라이트 점멸/이동 중 유지, 품명·사용자 주의사항·빈 템플릿 표시를 적용했다. 64단계는 경로 PASS 일반 부품 6개·볼트/너트 배치 41개·LV CONT 예외 1개·미해결 일반 부품 16개로 구성되며 전체 경로 검증 완료가 아니다. [최종 검증](END_TO_END_V14_RESULT.md), [변경 정책](CHANGES_V14.md), [릴레이 검사 형상 수정](RELAY_SWEEP_ORIENTATION_FIX.md), [GUI 스레드 수정](EXE_VTK_THREAD_FIX.md).

2026-10-18 후속 승인: 모든 부품의 초기 겹침 예외를 **위치별 감소 허용(v10)**으로 변경했습니다. 초기 겹침 쌍에서 재증가를 차단하고, 교차 해소 후와 처음부터 겹치지 않은 다른 쌍은 연속 검사하며 원형상 종점 분리를 요구합니다. 같은 상대 내부의 국소 새 충돌 및 검사 위치 사이의 재증가는 배제하지 못합니다. [최신 감소 예외 정책](DECREASING_OVERLAP_POLICY.md), [이전 고정 초기 영역 정책](INITIAL_REGION_POLICY.md), [볼트 전용 정책](FASTENER_POLICY.md)을 구분합니다. 지지 미확인 단계도 별도 경고가 있는 검토용 초안으로만 허용하며 검토용 초안을 검증 완료로 세지 않습니다.

## 우선 후속 작업

1. 실제 모델의 초기 관통·불확실 경로·지지 판정 진단을 바탕으로 전체 순서 완료율을 개선합니다. 접촉·경로 spawn 격리는 완료했고 STEP 읽기/영상 작업 전체 격리는 별도 보강 대상입니다.
2. STEPCAF/XDE 트리, occurrence 이름·색상·부모 변환을 현재 STEPControl 솔리드 추출 대신 연결합니다.
3. 그룹 후보에 양방향 BREP 거리/강체 변환 검증을 추가하고 실제 18부품 정답 검토를 진행합니다.
4. MariaDB zip 런타임·라이선스·전용 데이터 디렉터리 bootstrap을 패키징하고 독립 Windows 10/11에서 설치 시험합니다.
5. 동일 평가 집합의 기본/LightGBM 비교, 품종별 하락 제한, bundle 승격·복원 트랜잭션을 완성합니다.
