# v22 파일명 분류 확장·회전 매칭 보완

작업일: 2026-10-22. 범위는 STEP 읽기·부품 종류 분류·완제품/개별 부품 대응 확인까지만이다. 접촉 그래프 생성, 간섭·분해 경로 검사, 순서 생성, 학습·모델 평가, 영상 생성은 실행하지 않는다. 바탕화면의 제공파일과 `data_example`은 읽기 전용으로 취급한다.

## 분류 규칙

기존 `MBD-`, `PLT-`, `BLK-`, `BUS-`, `RLY-`, `COV-`, `SEL-`, `AIR-`, `BLT-`, `NUT-`, `HVSC 2800`, `LV CONT` 등의 기존 규칙을 먼저 적용한다. 뒤에 토큰 경계가 있는 별칭을 추가한다. 파일명을 변경할 필요는 없다.

| 추가 이름 예 | 기존 부품 종류 |
|---|---|
| BOLT_M4_10, BOLT_SIDE_M4_12_S09, SCREW_M3_12 | BOLT |
| NUT_M5 | NUT |
| BUS_N_IN, BUS_ELBOW_LEFT_S08 | BUSBAR |
| HSG_DRUM_S08, HOUSING_… | BODY |
| CARRIER_ANNULAR_S08, PLATE_… | PLATE |
| CONTACTOR_BODY, CONTACTOR_S10, PRE_RELAY_S08, PRECHARGE_RELAY_BODY | RELAY |
| COVER_HALF_S08 | COVER |
| GASKET_RING_S08 | SEAL |
| HV_CASE_2P_S08, HV_SOCKET_CONTACT, HV_PIN_S10 | HV_CONNECTOR |
| LV_SOCKET, LV_REAR_SOCKET_S03 | LV_CONNECTOR |

`XBUS_…`, `MY_BOLT_…`, `BOLTED_BRACKET` 같은 부분 문자열을 임의로 볼트·버스바로 분류하지 않는다. 접촉기의 단자 `CONTACTOR_TERMINAL`을 접촉기 본체로 오분류하지 않는다.

퓨즈·PCB·저항·센서·지지구 등에는 현재 정확하게 대응하는 PartType이 없는 경우가 있다. 이들은 이름을 유지한 `UNKNOWN` 일반 부품이다. 이는 STEP 불러오기 실패나 미매칭이 아니다. 기존 enum/학습 특징 체계를 임의로 확장하거나 다른 종류로 위장하지 않는다.

## S08 회전 매칭

원인: 기존 매칭은 체적·면적·축 정렬 경계 상자 크기를 비교한다. 임의 각도 회전은 경계 상자 크기를 바꾸므로, S08의 실제로 같은 부품 27개가 기존 크기 조건을 통과하지 못했다.

추가 순서:

1. 기존 엄격 매칭을 모두 완료한다.
2. 기존 미매칭 전용 AIR-BENT 재시도(상대 0.1%, 위치 0.005mm)를 그대로 수행한다.
3. 아직 미매칭인 바디에만 체적·면적 + 회전/평행이동 불변의 관성 고유값·면 종류/면적 목록·곡선 종류/모서리 길이 목록을 비교한다.
4. 이 단계의 상대 허용치는 기존 엄격 허용치와 1e-4 중 작은 값이다. 기존 간섭 허용치와는 무관하다. 여러 바디의 상대 중심 거리 조건과 조합 수 제한도 유지한다.
5. 한 바디가 여러 다른 부품 정의와 경쟁하면 원칙적으로 미매칭으로 남긴다. 같은 정의의 반복 배치는 바디 집합이 서로 겹치지 않는 경우 각각 허용한다.
6. S08의 좌·우 버스바 4개는 위 불변 특징이 동일했다. 이 경우에만 **STEP 자체의 원래 제품/부품 참조명**을 추가 대조한다. 형상 특징에 이미 통과한 정의 중 이름이 하나에 정확하게 일치해야 한다. `part_id | description` 형식은 `|` 앞의 명시적 ID만 사용하며 설명 문자열의 부분 일치로 추측하지 않는다.
7. STEP 메타데이터는 중첩 참조의 배치를 따라 읽고, 현재 바디의 월드 경계 상자·체적·면적에 대응시킨다. 장면 원본 해시도 재확인한다. 기존 도형·바디 ID·배치를 수정하지 않는다. 동봉 JSON 라벨이나 생성 스크립트는 실제 매칭에 사용/실행하지 않는다.
8. 이름이 없거나 여러 개, 특징 계산 실패, 겹치는 후보이면 미매칭을 유지한다. 이름만으로 형상 검증을 대신하지 않는다.

기존에 매칭된 바디/그룹 ID·이름·멤버는 회전 재시도가 가져가지 않는다. 회전 특징은 수학적으로 임의의 모든 형상에 대한 완전한 합동 증명은 아니며, 보수적 추가 대응 근거다. 불확실한 정의는 자동으로 묶지 않는다.

## 변경하지 않은 것

- 접촉 거리, 간섭 epsilon, 초기 겹침·감소 허용 기준, Boolean·분해 경로 검사.
- 순서 탐색과 일반 부품/볼트·너트 분리 알고리즘, 체결 방향 계산.
- 수동 그룹화·구매 모듈 단위 묶기 정책. 동봉 JSON의 구매 모듈/조립순서를 자동 가져오는 기능은 이번 수정에 포함하지 않는다.
- 학습·자동 적용 설정과 코드, 기존 프로젝트의 저장 스냅샷·편집/확정 순서.
- 원본 STEP 및 기존 ZIP. ZIP은 생성하지 않는다.

새 규칙은 새 파일 분석에 적용한다. 기존 저장 프로젝트의 미매칭 그룹을 열 때 자동으로 재구성하거나 확정 순서를 덮어쓰지 않는다. 기존에 분석한 S08의 그룹을 새 대응으로 바꾸려면 원본 STEP/부품을 새로 분석해야 한다.

변경 전후 원시 증거는 `build/v22-recognition-before.json`, `build/v22-recognition-final.json`, 요약은 `build/v22-recognition-comparison.json`에 기록한다. 최종 결과는 [인식 확인 결과](RECOGNITION_V22_RESULT.md)를 참고한다.
