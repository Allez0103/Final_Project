# v21 구현 결과 — 학습 실행·검증 제외

작업일: 2026-10-22

## 결론

공통 주기의 순서/방향 모델 순차 학습, 유휴 실행·자원 한도·중단/재개, 계열 분리 비교와 조합별 적용 판정, 버전별 모델 관리·복원을 구현하고 프로젝트 루트의 `PA2.exe`를 갱신했다.

**학습 기능은 코드 구현·구문 확인·EXE 포함 확인까지만 수행했다. 모델 학습, 학습 데이터 분리/성능 평가, 자동 적용/복원의 학습 기능 동작 시험은 의도적으로 하지 않았다.** 사용자가 앱에 더미 프로젝트를 준비하면 별도 요청으로 진행한다. 이 문서는 학습 기능이 실제 데이터에서 검증 완료되었다는 뜻이 아니다.

자동 학습·자동 적용의 기본값은 OFF다. 더미 학습용 프로젝트나 모델 가중치를 임의로 만들지 않았다. 이번 일반 회귀 시험의 임시 형상/DB와 GUI 빈 DB는 사용자 프로젝트나 학습 자료에 합치지 않았다.

구현 정책과 이후 검증 순서는 [공통 학습 주기 명세](LEARNING_LIFECYCLE_V21.md)에 기록했다.

## 구현 내용

- 동일 확정 데이터 스냅샷·동일 계열 분리 목록에서 순서 LGBMRanker → 방향 LGBMRanker 순차 학습.
- 최초 30계열 AND 1,000선택 사례, 재학습은 24시간 AND (신규 5계열 OR 500선택 사례). 중복 확정은 신규량으로 반복 집계하지 않음.
- 방향 사례/다양성 부족 시 방향 역할만 보류. 예외 포함 선호와 물리 판정 근거는 구분.
- 저비용 선호 사전 필터 → 현재 모델/기존 규칙과 실제 CAD 비교 → 순서만/방향만/둘 모두 조합별 판정.
- 추천 모델은 기존 TwoStage 구조 내부의 우선순위만 변경. 일반 부품 경로 검사, 예외 부품 정책, 체결부 배치·방향, 수동생성·편집·확정·영상 정책은 유지.
- 추가 CAD 계산 없는 ML 특징. 기존 6축만 재정렬, 첫 PASS 종료 유지.
- 유휴 작업 프로세스 한 개·수치 연산 1스레드·낮은 우선순위·시간/RSS 한도. 사용자 입력/전경 작업/종료 시 중단. 역할과 완료 평가 실행 단위로 체크포인트 유지.
- 모델 파일/체크섬/역할·특징 스키마/라이브러리 주버전 관리, 모델 쌍의 단일 SQL 읽기·원자적 적용과 감사 이력.
- 생성 시작 모델 고정. 손상·비호환·비유한 예측 시 이전 검증 쌍 또는 기존 규칙으로 복원하는 처리.
- 설정의 자동 학습/적용 및 자원·임계값 항목, 학습 현황의 현재 모델·단계/보류 사유·이력·평가 통과 모델 적용·이전 모델 복원.
- `learning_cycles`, `model_activations` 추가. 기존 테이블 구조/확정 순서를 덮어쓰지 않음. Alembic `0003_learning_lifecycle` 추가.

회귀 시험은 `tests/test_scene_learning_database.py`, `tests/test_v20_improvements.py`를 통째로 제외해 기존 학습 실행 시험이 섞이지 않게 했다. 시험과 GUI 시작에는 `PA2_DISABLE_BACKGROUND_LEARNING=1`을 적용하고 프로젝트 내부의 별도 임시 데이터 폴더를 사용했다. 학습 검증을 생략하기 위해 학습 기준을 낮추거나 가짜 모델을 만들지 않았다.

최초 일반 회귀 시험도 240 통과/1 건너뜀(51.66초)이었으며, 최종 소스 상태에서 다시 위 결과를 확인했다.

## 성능 비교 해석

v20 실제 제품의 자동생성 952.046초 / 후보 768 / 신규 경로 191 / 전체 초안 62단계, 수동생성 0.113초 / 경로 검사 0 / 62단계는 **이전 버전 기록**이다.

이번에는 학습도 학습된 모델의 전체 생성도 실행하지 않았으므로 새 모델의 검사 수·시간·생성 단계 수 개선량은 미측정이다. 기존 240개 일반 회귀 시험 통과를 학습 성능 개선이나 실제 제품 전체 경로 검증으로 바꾸어 해석하지 않는다.
