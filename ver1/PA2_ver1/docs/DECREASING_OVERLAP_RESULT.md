# 초기 겹침 감소 예외 적용 결과

## 결론

**20/64 → 32/64단계로 12단계 증가했지만, 전체 순서는 완성되지 않았습니다.** 커버와 씰의 위쪽(+Z) 제거가 실제 잔여 조립체 검사에서도 통과했습니다. 결과 상태는 `REVIEW_REQUIRED`입니다. 이 수치는 설정된 유한 방향·탐색 한도에서 확보한 최장 순서이며, 가능한 모든 조립·분해 방법의 최대치나 불가능 증명이 아닙니다.

| 정책 | path/planner-v10-decreasing-overlap-review |

모든 단계가 검토용입니다. 겹침 감소는 최대 0.5 mm 간격으로 검사하며, 검사 위치 사이의 재증가 및 같은 상대 부품 내부의 국소 새 충돌을 배제하지 못합니다. 교차가 해소된 뒤와 처음부터 겹치지 않은 상대는 기존 연속 경로 검사를 사용하고 종점 분리를 요구합니다. [정책 및 한계](DECREASING_OVERLAP_POLICY.md).

## 새로 포함된 12단계

아래 번호는 **분해 순서**입니다. 조립 순서는 확보한 분해 순서를 역순으로 배치합니다.

| 분해 단계 | 부품 | 방향 |
|---|---|---|
| 21 | COV-KD000 | +Z |
| 22 | SEL-KD000 | +Z |
| 23–32 | BLT-WASM620R #19, #18, #11, #23, #15, #14, #16, #17, #22, #20 | 각 채택 방향은 원본 결과에 기록 |

커버의 제거 거리는 34.720577 mm, 씰은 34.470577 mm입니다. 커버–씰 별도 +Z 쌍 검사에서는 2.5 mm에서 교차 부피 0, 씰–본체는 0.25 mm에서 교차 부피 0을 확인한 뒤 남은 연속 경로가 통과했습니다. 중간 표면 접촉은 가능하며 이 위치가 양의 간격이 확보된 최초 위치라는 뜻은 아닙니다.

최종 채택된 32단계에는 너트가 포함되지 않습니다. 중간 진행 안내의 너트 추가 설명은 최종 결과와 달라 정정합니다.

## 남은 32개

최장 순서의 끝 상태에서 남은 **32개 모두**를 검사했습니다. 중복 제거한 418방향은 BLOCKED 374, UNKNOWN 44입니다.

- **23개:** 검사한 방향 모두 차단. 겹침 부피 재증가 또는 이동 경로 충돌입니다.
- **9개:** 미판정 방향이 남음. 다른 방향은 차단일 수 있습니다.
  - RLY-KET400 #1/#2: 이동 형상 정밀 유효성·제한된 보정 기준 미통과(각 18방향).
  - BLT-WASM612A #1~#4: 각각 한 방향에서 상대 릴레이의 형상 유효성 문제로 미판정. 볼트 자체가 새로 무효화됐다는 뜻은 아닙니다.
  - source 바디 41, 42, 44: source 바디 40과의 곡면 이동 영역 미해결. 바디 44에는 시간 제한 미판정도 남았습니다.

주요 차단 상대는 MBD-KD000(잔여 24개 그룹의 적어도 한 방향), BUS-KD200(21개 그룹의 적어도 한 방향)입니다. 상대별 수치는 중복되며 부품 수 합계가 아닙니다. 예를 들어 +Z 방향에서 BUS-KD200은 BLT-WASM620R #12에, 그 볼트는 BUS-KD100에 차단됩니다. 이를 곧바로 모든 이동 방식의 물리적 불가능으로 해석해서는 안 됩니다.

미세한 재증가도 정책에 따라 차단됩니다. 예: source 바디 2의 +Z 0.01 mm 이동에서 본체와의 교차 부피는 13.76368375 → 13.76468371 mm³로 증가하여, 현재 상대 부피 오차 기준을 초과했습니다. 결과를 늘리려고 이 기준을 추가로 완화하지 않았습니다.

## 검증 및 사용

- 자동 시험: **144 passed, 1 skipped, 2 warnings**. 건너뛴 항목은 환경 변수로 외부 STEP을 지정하는 시험이며, 제공 모델은 별도 실제 실행으로 검증했습니다.
- 최종 채택 경로 감사: 32단계의 잔여 상태 연결·조립 역순 일치, 감소 예외 30쌍의 기록된 부피 비증가·최대 위치 간격·교차 해소·연속 후속 경로 PASS 확인. 이는 연속 감소의 추가 증명은 아닙니다.
- `dist/PA2/PA2.exe` 재빌드 및 패키지 native smoke 종료 코드 0. v10 적용, 감소 예외 REVIEW_REQUIRED, 곡면 검사 PASS 확인.
- 참고자료 23개와 원본 로고 1개의 SHA-256 일치. 원본 CAD·명세·참고자료는 수정하지 않았습니다.
- 기존 GUI 초안·확정본은 덮어쓰지 않았습니다. 최신 실행 파일을 다시 열고 순서를 생성하면 새 정책이 적용됩니다. 이번 실측 계획은 아래 JSON에 보관했습니다.
- v9 중간 실행은 씰의 중간 표면 접촉에 대한 반복 거리 계산을 개선하기 위해 중단했습니다. 최종 판정·실측은 v10 결과만 사용합니다.
