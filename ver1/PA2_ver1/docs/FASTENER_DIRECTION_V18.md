# 볼트·너트 방향 보완 v18

## 변경 기준

- 볼트는 가장 긴 원통면으로 몸통 축을 정하고, 같은 축을 따르는 넓은 머리·와셔 면의 위치로 머리 쪽을 판별한다. 분해 방향은 머리 쪽이며 조립 방향은 반대다. 모델의 +Z로 일괄 고정하지 않는다.
- 너트는 기존 접촉 그래프에 연결된 볼트가 있고 축이 일치하면 볼트 머리에서 멀어지는 쪽을 사용한다. 연결 볼트가 없으면 기존 체결 대상과 너트의 위치 차이를 축에 투영한다.
- 머리 또는 축 판별이 어려운 형상은 위치 정보로 방향을 지정한다. 축 방향 투영값이 사실상 0이면 +Z, +Y, +X 순으로 결정한다. 사용자는 기존과 같이 방향을 편집할 수 있다.
- 기존 방향 힌트 요청에서 면 특성을 함께 읽는다. 새 접촉면 계산, Boolean 교집합, 이동 경로 검사는 추가하지 않는다. 한 순서 생성 작업의 native worker에서 결과를 재사용한다.
- 일반 부품 탐색 전에 볼트·너트 힌트를 한 번 저장해, 탐색 시간 예산 소진 후에도 머리 방향을 사용할 수 있게 했다. 삽입 단계에서는 저장한 힌트를 읽는다.
- 새 자동 순서 생성부터 적용한다. 기존에 저장·확정한 순서와 사용자가 수정한 방향을 소급해서 덮어쓰지 않는다.

## 실제 형상 확인

v17의 64개 그룹, 이동 부품 63개, 볼트 37개·너트 4개를 사용했다. LV CONT, HVSC 2800 #1/#2, AIR-BENT0A 예외 설정을 유지했다. 제공 원본을 다시 수정하거나 기존 초안을 저장하지 않고 기존 스냅샷을 읽었다.

| 항목 | 결과 |
|---|---:|
| 머리 방향 판별 볼트 | 37/37개 |
| 기존과 반대 방향으로 보정된 볼트 | 8개 |
| 너트 | 4개, 기존 대상 위치 기준 방향 유지 |
| 볼트·너트 방향 힌트 요청 | 기존 41회 → 41회 |
| 추가 접촉·Boolean·경로 검사 | 0회 |
| 기존 축 분석 시간 | 약 0.061초 |
| 새 축·머리 분석 시간 | 약 0.103초 |

위 시간은 실제 41개 형상을 메모리에 읽고 면 목록을 준비한 다음 측정한 분석 시간이다. 파일 읽기와 worker 통신을 포함한 전체 순서 생성 시간이 아니다. 분석 자체의 증가는 약 0.042초다.

방향이 바뀐 볼트는 BLT-WASM620R #3/#4/#12/#13/#15/#22/#23, BLT-WASM612A #2다. 모두 기존 −Z 계열에서 머리가 있는 +Z 계열로 바뀌었다. 옆으로 체결된 볼트는 실제 머리 축인 ±X/±Y 방향을 유지했다.

## 검증 범위와 결과 파일

이번에는 일반 부품 탐색을 다시 실행하지 않았다. 일반 부품만 탐색하는 기존 구조를 유지하고, 기존 v17 순서의 사본에서 볼트·너트 방향과 새 방향의 이탈 거리를 다시 정했다. planning-v18-fastener-directions.json의 일반 탐색 횟수·시간은 v17에서 물려받은 값이며 v18 신규 탐색 실측으로 해석하면 안 된다.

간섭 판정과 BLK-KD000의 미해결 상태는 바뀌지 않았다. 머리 방향 판별은 간섭 통과를 보증하는 검사가 아니다.

전체 회귀시험은 235개 통과, 외부 입력 별도 시험 1개 건너뜀, 기존 VTK/NumPy 경고 10개였다. 최신 힌트 선계산 변경 뒤 전체 시험을 다시 실행해 61.67초에 완료했다. 별도 12개 방향 시험도 통과했다.

수정 방향을 적용한 63단계 영상은 219.93초에 생성했다. 영상 길이는 254초, 1920×1080/30fps, 7,620프레임이며 전 프레임 디코딩을 통과했다. 방향 변경에 따라 AUTO 카메라 회전 구간이 줄어 이전 275초 영상과 길이가 다르므로 이를 동일 길이 렌더 성능 개선으로 비교하지 않는다. 볼트 37개 모두 머리 쪽에서 출발해 최종 조립 위치로 접근하는 장면 이동값을 확인했다.

실제 배포 EXE에서 대상 부품이 볼트 위에 있어 기존 중심 기준으로는 잘못된 방향이 선택되는 합성 형상을 검사했다. 새 결과는 분해 +Z, 조립 −Z, 방향 방법 bolt_head_axis, 경로 검사 0회였다. 배포 코드·자산·아이콘도 현재 소스와 일치했다. EXE SHA-256은 3f1602b93cd7e0c40bc4dfd3cb7731a19d2aa584a4b9679e99f601c0e2c4caa4다.

기존 프로젝트의 사용자 편집 순서·방향과 원래 확정본을 재조회해 보존을 확인했다. 기존 자동 순서에서 방향만 보완한 영상 사본을 별도로 생성했으며, 프로젝트의 현재 초안·확정본을 교체하지 않았다.

재빌드한 EXE의 실제 창 실행과 기존 프로젝트 재열기도 통과했다. 64개 그룹·63개 단계·예외 4개가 복원됐고 실제 3D 장면 렌더링을 확인했다. 제공 자료와 원본 로고의 SHA-256 24개도 기존 기록과 일치했다.

- runtime-data/native-validation/fastener-direction-v18.json: 41개 방향, 머리 근거, 변경 전후 비교, 분석 시간.
- planning-v18-fastener-directions.json: 기존 순서를 보존한 렌더용 사본.
- video-v18-fastener-directions/video-validation.json: 전체 63단계 영상·전체 프레임 디코딩·고정 카메라·점멸·CAD 재검사 0회 확인.
- tests-v18-fastener-final.log: 전체 회귀시험.
- tests-v18-fastener-targeted.log: 6방향 볼트, 대칭 형상, 너트 연결 방향, 힌트 재사용, 탐색 예산 소진 후 머리 방향 유지 시험.
- build-v18-fastener.log: 테스트 후 실행 파일 재빌드.
- packaged-source-check-v18.json / native-smoke-v18.json / gui-smoke-v18.json: 배포 코드 일치·실제 EXE 계산·창 실행 확인.
- reference-integrity-v18.json: 제공 원본 및 원본 로고 24개 해시 보존 확인.
- saved-plan-and-motion-v18.json: 기존 편집·확정본 보존 및 37개 볼트의 머리 쪽 출발·조립 접근 확인.

배포 파일은 PA2/PA2.exe다. 이전 v17 결과와 영상은 보존했다.
