# 릴레이 계산용 형상 보정 기준 변경 및 확인

사용자 요청 범위: 제안한 보정 기준을 적용하고 릴레이 두 그룹의 입력 형상 검증 통과 여부까지만 확인한다. 전체 순서 생성과 영상 생성은 실행하지 않았다.

## 적용 기준

- 계산용 복사본의 최대 저장 허용오차: **0.01 mm**.
- 보정 전후 체적 변화율: **0.001% 이하** (`1e-5`, 절대 변화 하한 `1e-9 mm³` 유지).
- 간섭 판정 epsilon: **0.001 mm 유지**. 충돌·경로 판정 코드는 변경하지 않았다.
- 외곽 경계 변화: 기존 epsilon **0.001 mm 이하** 유지.
- 보정 후 정밀 기하 유효성, 면·모서리·정점 개수 유지 조건도 유지.
- 새 보정 정책: `parameter-repair-v2-bounded`. 기존 저장 결과를 재판정하거나 덮어쓰지 않았다.

## 실제 형상 확인 결과

중단된 v13 실행의 프로젝트에서 관리 스냅샷을 읽어 검사했다. 스냅샷 ID는 읽기 전용 SQLite 조회로 취득했으며, 정확한 ID와 입력 파일 SHA-256은 아래 JSON에 기록했다.

| 검사 항목 | RLY-KET400 #1 | RLY-KET400 #2 |
|---|---:|---:|
| 포함 바디 수 | 9 | 9 |
| 보정 후 정밀 기하 유효성 | 통과 | 통과 |
| 계산 입력 채택 | 통과 | 통과 |
| 최대 저장 허용오차 | 0.004973695 mm | 0.004973695 mm |
| 체적 변화 | 약 0.061244557 mm³ | 약 0.061244557 mm³ |
| 허용 체적 변화 | 약 0.432547351 mm³ | 약 0.432547351 mm³ |
| 외곽 경계 변화 | 0.000184372 mm | 0.000184372 mm |
| 면·모서리·정점 개수 유지 | 통과 | 통과 |
| 보정 전 원형의 속성 유지 | 확인 | 확인 |

두 그룹 모두 기존 엄격한 허용 기준으로는 실패하고 새 기준으로는 통과함을 확인했다. 실제 경로 검사에서 사용하는 `ConservativePathChecker._prepare_group()`을 호출했으며, 충돌 검사는 수행하지 않았다. 따라서 이 결과는 **형상 입력 검증 통과**를 뜻하며, 릴레이의 실제 분해 경로 통과나 전체 순서 완성을 뜻하지 않는다.

관리 캐시 입력 18개 파일은 검사 전후 SHA-256이 모두 일치했다. 원본 제공 파일은 수정하지 않았다.
