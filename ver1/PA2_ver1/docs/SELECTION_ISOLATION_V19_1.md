# v19.1 — 그룹화용 다중선택 자동 표시 제한

## 동작

- 부품 목록에서 Ctrl/Shift로 두 개 이상 선택하면 선택한 부품만 3D 화면에 표시한다.
- 선택 항목을 바꾸면 표시 대상도 따라 바뀐다. 한 개만 선택하거나 선택을 해제하면 자동 표시 제한 이전의 상태로 복원한다. 기존에 사용자가 숨긴 부품이 있다면 그 상태를 유지한다.
- ‘전체 표시’ 버튼으로 즉시 전체 모델을 다시 볼 수 있다. ‘선택 숨김’·‘선택만 보기’의 명시적 수동 표시 명령도 유지한다.
- 카메라 위치·각도·확대율을 자동으로 바꾸지 않는다. 필요하면 기존 ‘화면 맞춤’을 사용한다.
- 순서 카드의 다중선택은 단계 이동용이므로 이 동작을 적용하지 않는다. 카드에서 선택하면 부품 목록의 임시 표시 제한을 해제한다.
- 부품 목록에서 선택하면 재생과 단계 미리보기를 멈춰 표시 상태가 재생 프레임에 의해 덮이지 않도록 한다. 재생·타임라인 이동·미리보기 갱신 시에는 임시 제한을 해제한다.
- 기준 부품이나 아직 순서가 없는 부품을 함께 선택해도 카드 동기화가 부품 목록의 선택을 지우지 않는다. 기준 부품을 포함한 그룹화 금지는 유지한다.

## 변경하지 않은 범위

화면의 actor 표시·하이라이트만 바꾼다. 부품 유형, 바디 구성, 접촉·간섭 기준, 일반 부품/볼트·너트 분리 알고리즘, 확정 순서와 영상 생성 데이터는 변경하지 않는다. 제공 원본은 수정하지 않는다.

이번에는 전체 CAD 순서 탐색이나 긴 영상 생성은 반복하지 않는다. 직전 v19의 전체 흐름 시험과 별개로, 표시 기능의 자동 회귀 시험과 기존 프로젝트를 재열어 실제 EXE의 선택·복원·카드 선택·카메라 유지·데이터 불변을 검증한다. 긴 영상의 기존 실측은 END_TO_END_V19_RESULT.md에 보존한다.
