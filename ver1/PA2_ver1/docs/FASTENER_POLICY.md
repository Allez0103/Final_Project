# 볼트 체결 예외와 검토용 순서 초안

이 문서는 이전 볼트 전용 정책과 당시 실측 기록입니다. 이후 사용자 승인으로 모든 부품의 초기 영역 예외가 기본 적용되었습니다. 최신 정책·실측은 [INITIAL_REGION_POLICY.md](INITIAL_REGION_POLICY.md)를 참고하세요. 전체 부품 옵션을 끈 경우에는 아래의 볼트 전용 옵션을 사용할 수 있습니다.

## 승인 및 기본값

2026-10-18 사용자가 볼트 체결 때문에 생긴 초기 겹침을 예외 처리하도록 요청했고, 후속 질문에서 지지 미확인 단계의 검토용 초안 생성도 허용했습니다. 원 명세 10.6의 엄격한 초기 관통 차단에 대한 제한적 변경입니다. 제공 원본과 명세 파일 자체는 수정하지 않습니다.

- `bolt_initial_overlap_enabled=true`: 볼트 축 방향 초기 체결 겹침 예외.
- `allow_support_unknown_draft=true`: 경로가 통과한 단계만 지지 미확인 경고를 붙여 초안에 포함.
- 두 설정은 설정 창에서 독립적으로 끌 수 있습니다. 기존 설정 파일에 없는 필드는 새 기본값을 사용합니다.

## 체결 예외 조건

1. 이동 그룹이 BOLT이고 양쪽 그룹의 형상이 유효해야 합니다. 상대는 BODY, BLOCK, PLATE, NUT, BUSBAR, RELAY, COVER, HV_CONNECTOR, LV_CONNECTOR 중 하나여야 합니다. 다른 볼트, 씰, 미분류 부품의 겹침에는 적용하지 않습니다.
2. 볼트의 실제 원통면 중 면적이 가장 큰 면에서 축 근거를 얻습니다. 축 근거가 없거나 이동 방향이 축과 평행하지 않으면 예외로 통과시키지 않습니다.
3. 초기 BREP 교차 체적을 측정합니다. 계산용 상대 형상에서 볼트의 초기 위치가 차지하는 영역만 뺀 `O' = O \ M(0)`을 만듭니다. 상대 부품 전체가 사라지는 경우는 허용하지 않습니다.
4. 전체 이동 sweep이 O'를 새로 관통하지 않는지 검사합니다. 상대 부품 자체의 다른 위치에 새로 부딪히거나 별도 얇은 장애물을 지나가는 경우도 차단합니다.
5. 종점은 원래 상대 형상 O와 분리되어야 합니다. Boolean/유효성/경로 증명 실패 및 timeout은 UNKNOWN입니다.

이는 사용자가 허용한 체결 간섭 모델입니다. 실제 나사산·회전·토크·공구 접근성·변형·강도를 검증한 것이 아닙니다. 임의의 겹침 비율 임계값으로 모든 간섭을 허용하지 않습니다. 원본 또는 저장된 BREP를 고치는 것이 아니라 worker의 일시적 계산 형상만 사용합니다.

경로 정책 버전은 `path-v3-fastener-region`, 계획 버전은 `planner-v3-fastener-region`입니다. 예외 상대 ID, 초기 교차 체적과 볼트 체적 대비 비율, 쌍 판정을 `PathCheckResult.evidence.fastener_exceptions`에 저장합니다. 일반 검증 단계와 구별되는 `FASTENER_EXCEPTION` 표시 및 주의사항을 제공합니다.

## 지지 미확인 초안

지지 검사는 그대로 실행합니다. 경로 PASS이고 지지만 UNKNOWN인 경우에 한해 초안에 포함하고, 미지지 부품 ID 목록과 원래 경로 이유를 기록합니다. 해당 단계는 `SUPPORT_UNVERIFIED`, 계획은 `REVIEW_REQUIRED`입니다. 초안 전체가 채워져도 지지가 미검증이면 COMPLETE로 올리지 않습니다. 충돌 또는 경로 미판정은 여전히 제외합니다.

순서 목록에는 `[지지 미검증]`, 주의사항에는 작업 지그·고정 확인 경고가 표시됩니다. 볼트 체결 예외와 지지 미확인이 함께 적용된 경우 두 정보를 모두 유지합니다. JSON/DB 저장·재열기에서도 경고 상태가 보존됩니다. 부분 초안은 기존 `Plan.validate()`의 누락 검사로 확정되지 않습니다. 사용자 확정이나 수동 수정은 기하 검증의 증거를 새로 만들지 않습니다.

부분 초안의 미리보기에서는 순서를 만들지 못한 부품을 원래 조립 위치에 남겨 둡니다. 이를 숨기거나 제거가 검증된 것으로 간주하지 않습니다.

## 검증

- 자동 시험 최종 실행: 65 passed, 1 skipped, 2 warnings (선택적 실제 STEP 자동 시험은 환경 변수 미설정으로 skip; 아래 별도 실측 수행).
- GUI offscreen 검사: 3개 화면, 새 설정 2개 기본 활성화, 순서 목록의 `[지지 미검증]` 표시 확인.
- 최종 PyInstaller 실행 파일 재빌드 후 `--native-smoke`: 종료 코드 0, 합성 볼트 체결 예외 1단계 COMPLETE, 로고 포함 확인 (`packaged-fastener-smoke.json`). 일반 GUI도 offscreen 환경에서 8초 이상 정상 실행 후 시험 종료.
- 제공 원본 및 로고 24개 SHA-256 재검사: 모두 일치.

- 합성 형상: 축 방향 이탈 허용, 엄격 모드 및 비볼트 차단, 옆 방향 차단, 더 깊이 이동 차단, 새 얇은 장애물 및 동일 상대 부품의 다른 위치 충돌 차단, 축 없는 볼트 차단, Boolean 실패 UNKNOWN.
- worker/계획 통합: 겹친 볼트의 제거·역산 조립 순서, 예외 상태·주의사항, 엄격 설정으로 복귀.
- 검토용 초안: 경로 PASS/지지 UNKNOWN만 채택, REVIEW_REQUIRED 유지, 기존 충돌 차단, 저장·재열기 경고 보존.
- 실제 모델: `runtime-data/native-validation/planning-fastener-review.json`에 완료 결과 기록. 아래 실측 요약 참조.

지지 예외를 아직 적용하지 않은 비교 실측(`planning-fastener.json`)에서는 371후보/약 449.39초, 볼트 체결 예외 후 경로가 통과한 18개의 볼트도 지지 UNKNOWN으로 채택되지 않았습니다. 이 비교는 사용자가 지지 미확인 초안을 추가 승인하기 전 정책입니다.

### 실제 완제품 최종 실측

- 65그룹 중 기준 부품을 제외한 이동 대상 64개, 접촉 121간선 재사용.
- 약 619.93초, 방향 후보 3,385건, native timeout 0.
- 결과 `REVIEW_REQUIRED`: 20/64단계의 부분 검토용 초안 생성. 제거열을 역순으로 조립 단계에 저장.
- 20단계 모두 지지 미검증 경고를 유지. 그중 18단계는 초기 볼트 체결 겹침 예외 적용, 2단계는 일반 경로 통과.
- 초안에 들어간 부품: BLT-WASM620R 10개, BLT-WASM520A 8개, BLT-WASM412B 2개.
- 남은 44개는 이번 탐색에서 채택되지 않음. 볼트 외 초기 관통, 새로운 이동 간섭, 경로 미판정 및 제한된 탐색이 남아 있으며 전체 조립 순서나 물리적 불가능을 증명한 결과가 아님.
- 출력 JSON의 20단계 각각에 대해 상태 키·방향·거리와 경로 PASS 증거의 대응, 제거열 역순, 그룹 중복 없음 및 예외 쌍의 PASS를 재검사함.

실측은 관리 영역 `runtime-data/real-model`의 검증 프로젝트에서 수행했습니다. 일반 실행에서 기존 프로젝트를 열고 순서 생성을 다시 실행하면 새 정책이 적용됩니다. 이전 초안·확정본을 자동으로 대체하지 않습니다.
